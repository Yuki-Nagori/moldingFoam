# 015 — 纤维取向与各向异性（纤维增强材料）

- 状态：planned
- 优先级：P3
- 依赖：001/002（基础流动求解）
- 预估规模：2–4 周

## 1. 背景与现状

短纤维增强热塑性（GF/CF 增强 PP/PA 等）的流动与最终性能强烈依赖
纤维取向：黏度呈各向异性，制品收缩/翘曲与纤维方向相关。当前
CrossWlf 为各向同性广义牛顿模型。

## 2. 目标与非目标

### 目标
1. 纤维取向张量 `a_ij` 的演化（Folgar–Tucker 或 ARD-RSC）；
2. 取向对黏度的修正（如 Lipscomb 各向异性黏度）；
3. 输出取向场供翘曲/结构分析使用。

### 非目标
- 纤维断裂/浓度演化；
- 长纤维/连续纤维。

## 3. 技术方案

- `a_ij` 作为张量场随流场输运 + 旋转/扩散源；
- 闭合近似：Hybrid/orthogonal；
- 黏度：`η = η0(T,γ̇) · f(a, aspect ratio)`;
- 与 CrossWlf 的层次关系：CrossWlf 提供基体剪切变稀，再叠加取向
  修正。

## 4. 工作拆解

1. 模型选型（Folgar–Tucker + 闭合）；
2. `a_ij` 输运方程实现与稳定化（张量有界性）；
3. 黏度各向异性耦合；
4. 验证：简单剪切取向解析（Jeffery 轨道）对拍；
5. 演示 case 与文档。

## 5. 验收标准（DoD）

- 简单剪切下 Jeffery 轨道/稳态取向角对拍；
- 取向场有界、守恒（迹为 1）；
- 缺省不启用时与现有行为一致；
- CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 张量方程数值刚性/有界性 | 采用成熟的闭合与限幅；小步长验证 |
| 参数繁多 | 字典化并给典型 GF/CF 缺省 |

## 7. 涉及文件

| 文件 | 改动 |
|------|------|
| `src/` 新取向模型 | 张量输运 |
| `src/viscosityModels/` | 各向异性黏度 |
| `case-contract`/演示 case | 材料参数 |
