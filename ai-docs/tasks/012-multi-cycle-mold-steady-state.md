# 012 — 多周期模温与周期稳态

- 状态：in-progress（2026-09-10：周期循环/流场重置已实现并验收；
  模温周期稳态收敛的验证待做）
- 优先级：P2
- 依赖：002（单周期集总模温已落地）、008（可选 CHT）
- 预估规模：3–5 天

## 1. 背景与现状

002 的模温只做单周期（首模次）演化并支持重启续读。真实注塑是
多模次循环：模温逐周期趋近周期稳态，周期稳态直接决定量产一致性。
当前无法在无人工干预下跑"连续 N 模次直至模温收敛"。

## 2. 目标与非目标

### 目标
1. 支持连续模次循环：每个周期结束（顶出）后重置流场/温度初值、保留
   模温状态，自动进入下一周期；
2. 周期稳态判据（模温/周期积分热流变化 < 容差）与自动停止；
3. 状态持久化（重启/续跑）。
4. 统计输出：每周期顶出时间、模温峰值/谷值、周期热平衡。

### 非目标
- 机械运动（开合模/顶出机构）建模；
- 制品取出后的冷却/收缩后处理。

## 3. 技术方案

- 求解器增加"周期结束→重置"钩子（`endTime` 或顶出后触发）；
- 场重置策略：保留模温状态（`moldingStage`/`moldThermalState`），
  `alpha.melt` 回零、`T/U/p` 回初值、交界面清理；
- 由 `system/controlDict` 或 `moldingDict` 配置 `nCycles` 与稳态容差；
- 与 `regIOobject` 持久化一致（003/006 的模式）。

## 4. 工作拆解

1. 周期循环框架与状态保留清单；
2. 场重置工具（含并行分解一致性）;
3. 周期稳态判据与日志/后处理；
4. 演示 case：简易板件 5–10 周期，检查模温收敛；
5. 文档与单元测试（重置逻辑）。

## 5. 验收标准（DoD）

- 连续 N 周期自动运行，状态保留/重置正确（**已完成**）；
- 模温随周期收敛到稳态（变化率 < 容差）（**待做**：需 002 模温变体
  多周期运行与收敛判据）；
- 单周期行为与 002 一致（回归）；
- CI 双架构绿。

验收记录（周期循环）：

- `moldingDict` 可选 `nCycles`（缺省 1）。每满足顶出判据时：若还有
  周期，重置流场（α、U、T、p、p_rgh 与其边界、面通量与动能）并回到
  filling 阶段（清除排气/闸口密封），**不触碰模温状态**；否则按原逻辑
  停机；
- 临时契约变体（`nCycles 2`、`endTime 1.6 s`）：cycle 1 顶出
  t = 1.1815 s（mass 2.107e-3 kg）→ 重置 → cycle 2 质量从
  1.9e-5 kg 重新充填到 9.39e-4 kg（t = 1.6 s），全程 0 个 NaN；
- 缺省 `nCycles 1` 的代码路径与 006/007 验收一致（无重置分支）；
- 提交哈希：随本任务提交后回填。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 重置不彻底导致场污染 | 显式初始化清单 + 每周期校验日志 |
| 多周期运行时长 | 演示 case 用小网格/短周期；仅夜间跑 |
| 与重启/续读语义冲突 | 周期索引与阶段状态一并持久化 |
