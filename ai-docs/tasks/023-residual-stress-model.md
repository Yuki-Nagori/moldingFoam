# 023 — 残余应力模型

- 状态：in-progress（2026-09-10：1D 自平衡弹性残余应力分布已落地；粘弹性历史与三维应力待做）
- 优先级：P2
- 依赖：022
- 预估规模：1–2 周

验收记录（第一阶段：1D 自平衡弹性残余应力）：

- `moldingWarpage::residualStress(T, h, sigma)`：由厚度方向温度剖面给出
  面内约束板的自平衡应力
  `sigma(y) = E/(1−nu)·α·((T(y)−Tref) − eps0)`、
  `eps0 = α·mean(T−Tref)`（Simpson 积分）；
- model test：线性剖面下应力与 `E/(1−nu)·α·(T−Tref)` 逐点一致
  （误差 <1e-12 MPa），全域应力积分均值为 2.9e-11 Pa（自平衡）；
- 待做：粘弹性/热粘弹历史演化（与 027 协同）、三维应力场与脱模后
  自平衡、基准件与文献对比。

## 1. 背景与现状

022 的翘曲 MVP 使用线弹性；真实残余应力来自不均匀冷却、保压压力
历史与层间收缩差，需要粘弹性/热粘弹演化与脱模后自平衡。

## 2. 目标与非目标

### 目标

1. 残余应力演化模型（热粘弹性）；
2. 与翘曲结果一致（应力→变形）；
3. 基准验证与定性分布。

### 非目标

- 疲劳/长期蠕变。

## 3. 技术方案

- 在 022 的结构框架内加入粘弹性本构（与 027 协同）；
- 应力松弛/体积松弛参数字典化。

## 4. 工作拆解

1. 本构选型与参数标定；
2. 实现与基准；
3. 与 022 翘曲一致；
4. 文档。

## 5. 验收标准（DoD）

- 基准残余应力分布定性正确；
- 与翘曲耦合自洽；
- 不影响流动；CI 双架构绿。
