# 033 — 空洞/张力场建模（018a 阶段 4）

- 状态：planned
- 优先级：P1
- 依赖：018a（后处理指标：voidFraction/精确 Tait/PVT 对拍 1.6e-6）、031
- 预估规模：1–2 周

## 1. 背景

018a 以 PVT 后处理指标实现封冻后空洞（`voidFraction` 场，压力路径与
PVT 一致 1.16%、密封冷却质量预算 4.1e-4），但求解器仍允许熔体压力
降到 −4.2 MPa 的张力；空洞没有显式体积/质量记账。

## 2. 目标

1. **张力限制**：封冻后压力下限 pv（缺省 0/蒸气压），密度限制在
   `rho(pv,T)`；
2. **显式空洞记账**：空洞体积分数与熔体质量分开守恒
   （`m_melt = Σ V(1−void) rho(pv,T)`）；
3. 密封冷却 case：空洞体积与 PVT 一致 <1%、无修正器下熔体质量
   守恒 <1e-3、压力平台在 pv；
4. 缺省不启用时现有 case 逐字节不变。

## 3. 技术方案

- 在热物性更新后对密封单元施加 p 下限（限幅 p→pv 并同步
  `correctRho`/能量），或引入空洞相 αvoid 的三相表述；
- 质量记账：熔体质量用 (1−void) 加权，进入 `massBudget` 仪表；
- 与 031 的压力一致定式协同（限幅后的压力方程源项一致性）。

## 4. 验收标准（DoD）

- `tests/cases/voidFraction` 扩展（张力限制开关 + 空洞守恒检查）；
- 模型测试（限幅/记账的单元检查）+ 全套回归绿；
- 密封冷却质量守恒 <1e-3（**无** `massFixGlobal`）。

## 5. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 压力限幅破坏压力方程一致性 | 与 031 的定式修复联调；逐步限幅 |
| 三相表述改动大 | 先两相 + 记账（等效），后三相 |
