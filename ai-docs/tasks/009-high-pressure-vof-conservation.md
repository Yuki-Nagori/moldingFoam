# 009 — 高压可压缩界面守恒（40–100 MPa 保压）

- 状态：planned
- 优先级：P1
- 依赖：006（周期完备化）
- 预估规模：1–2 周

## 1. 背景与现状

006 的契约 case 在 1.3 MPa 保压下质量守恒相对误差 9.305e-04，距
1e-3 阈值仅 ~7% 余量；误差随保压压力/密度比增大（2.5e5 时约 7e-4）。
真实注塑保压 40–100 MPa，熔体密度变化数个百分点，空气被压缩数百倍，
当前可压缩 VoF 的界面输运误差预计突破 1e-3，无法作为高压工况的
验收依据。

质量误差机理：VOF 输运的是体积分数 α，而质量是 αρ；可压缩条件下
α 方程的体积守恒与质量的守恒存在残差（`contErr`），界面处密度比
越大残差越大。

## 2. 目标与非目标

### 目标
1. 在高压保压（≥40 MPa）下契约 case 质量守恒相对误差 < 1e-3；
2. 不牺牲现有精度/稳定性；不修改上游源码；
3. 可量化：给出误差随压力/密度比/界面的标定曲线。

### 非目标
- 界面锐化算法重写；
- 相变成分/多组分输运。

## 3. 技术方案

候选（按代价排序，逐一评估）：

1. **通量修正**：仿照 `contErr` 机制，把 α 方程的体积通量与质量通量
   做一致性修正（例如用 `alphaRhoPhi` 重算界面压缩通量的质量权重）；
2. **压力限制的保压曲线**：工程案例上限定保压平台并减缓压力变化率，
   降低误差累积（已部分用于 006）；
3. **界面子循环/时间步控制**：以界面密度比为判据自适应收紧时间步与
   `nSubCycles`（成本可控的方案）；
4. **重写 α 方程为正则化的质量分数方程**（大改，需文献评审）；
5. 参考 `interIsoFoam`/`compressibleMultiphaseInterFoam` 的处理方式，
   评估能否局部复用思想。

建议先做 1/3 的量纲分析与误差标定实验，再决定是否进入 4。

## 4. 工作拆解

1. 基准：高压工况（40/80/100 MPa）复现误差曲线，定位主要贡献项；
2. 通量一致性修正原型（在 `moldingFoam` 覆写中实现，不动上游）；
3. 自适应界面时间步/子循环；
4. 验证：质量守恒、界面形状（气泡压缩解析）、稳定性；
5. 文档与契约更新。

### 误差标定实验（第一轮：设计缺陷已定位）

契约 case 变体：`switchPressure` 与保压曲线平台直接改为 40 MPa。
结果：V/P 切换由 **填充分数 0.9** 先触发（闸口压力仅 1.34 MPa），
随后保压目标从 1.34 MPa 阶跃到 40 MPa，求解器在 3e-4 s 内发散
（NaN）。结论：高压研究必须先构造**压力连续**的周期——切换压力
（保压设定压力）必须与充填末期闸口压力相当，例如提高注射流量
（充填压力 ∝ 流量）或减小/加长浇口，使 90% 填充时闸口压力即达到
目标保压压力；或让保压曲线从切换压力缓慢升到目标压力。

下一轮实验设计：

1. 提高注射流量或浇口阻力，使填充分数 0.9 时 `p_gate ≈ p_hold`；
2. 以此工况跑满周期，测质量守恒并记录界面两侧密度比
   （高压下空气密度接近熔体，密度比反而下降，误差未必随 p 单调）；
3. 若误差 > 1e-3：先试自适应界面子循环（按界面密度比/库朗数），
   再评估通量一致性修正；
4. 附加解析验证：封闭气泡在熔体压缩下的等温/等熵 p–V 关系。

## 5. 验收标准（DoD）

- 40 MPa 保压契约 case 质量守恒 < 1e-3；
- 误差-压力曲线单调可解释；
- 现有 1.3 MPa 案例误差不劣化；
- CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 通量修正破坏有界性/MULES | 与 MULES 限幅联合验证，先做小步长对照 |
| 成本上升 | 自适应子循环只在界面处生效 |
| 高压下 Tait 非线性与数值耦合 | 与物性/能量方程联合回归 |
