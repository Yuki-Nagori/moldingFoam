# 027 — 粘弹性本构模型

- 状态：planned
- 优先级：P2
- 依赖：001/007
- 预估规模：1–2 周

## 1. 背景与现状

当前 CrossWlf 为广义牛顿（无弹性）。聚合物熔体的弹性（法向应力、
挤出胀大、应力松弛）影响保压/翘曲/残余应力，需要粘弹性本构。

## 2. 目标与非目标

### 目标

1. 粘弹性本构（如 Giesekus/PTT）实现；
2. 启动剪切/振荡剪切基准验证；
3. 与流动耦合稳定；
4. 支撑 022/023 的残余应力。

### 非目标

- 多模式谱的完整标定。

## 3. 技术方案

- 在 `momentumTransport` 框架内自注册粘弹性模型（模块内）；
- 构型张量/应力输运方程；
- 基准：启动剪切应力增长、振荡剪切 G′/G″。

## 4. 工作拆解

1. 本构选型与稳定化；
2. 实现与基准；
3. 与流动耦合回归；
4. 文档。

## 5. 验收标准（DoD）

- 启动剪切/振荡剪切与解析一致；
- 缺省牛顿行为不变；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 高 Wi 数不稳定 | 成熟格式 + 限幅 + 小步长 |
