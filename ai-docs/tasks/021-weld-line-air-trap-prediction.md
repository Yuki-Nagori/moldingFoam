# 021 — 熔接痕与气穴预测

- 状态：planned
- 优先级：P1
- 依赖：006/003
- 预估规模：1–2 周

## 1. 背景与现状

006 已有排气封堵与 V/P 切换，003 已有困气诊断（连通域洪水填充）。
缺口是**熔接痕位置预测**（多股前沿相遇/汇流）与**气穴分布输出**，
这是注塑件外观与强度评估的核心指标。

## 2. 目标与非目标

### 目标

1. 熔接痕位置预测（前沿相遇检测与标记）；
2. 气穴分布输出（基于困气诊断的压力极小/封闭域）；
3. 基准件（多浇口/带芯）验证；
4. 输出场可供后处理。

### 非目标

- 熔接痕强度/力学性能定量；
- 表面形貌。

## 3. 技术方案

- 前沿到达时间场或 α 前沿相遇检测（相遇面即熔接痕）；
- 气穴：003 的困气连通域 + 局部压力极小，写成标记场；
- 输出 `weldLine`/`airTrap` 场（AUTO_WRITE）或 function object。

## 4. 工作拆解

1. 熔接痕检测算法与场输出；
2. 气穴标记与基准验证；
3. 多浇口/带芯基准 case；
4. CI 与文档。

## 5. 验收标准（DoD）

- 基准件熔接痕位置与解析/文献一致；
- 气穴与困气诊断一致；
- 不影响流动求解；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 阈值敏感 | 参数字典化 + 收敛研究 |
| 并行一致性 | 全局 gather 模式复用 |
