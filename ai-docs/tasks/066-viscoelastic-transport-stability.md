# 066：粘弹性输运、材料限步与相区一致性

- 状态：in-progress
- 优先级：P1
- 依赖：027 / 034 / 063
- 来源：2026-09-15 整体复核；承接 063 以外的明确剩余项

## 背景与现状

063 的单步反馈基准已约束 div(tau) 对动量的作用，但当前
`viscoelasticStress::addSup()` 仍是局部应力 ODE，无对流历史和熔体相权重。
`moldingViscoelastic::advance()` 的显式 RK2 对零流动松弛在 dt/lambda=3
时放大为 2.5，精确解为 exp(-3)。流动 Courant 限制不足以控制材料时间尺度。

## 目标与非目标

先解决材料松弛稳定性，再设计相一致应力输运，明确气相处理及入口历史。
高 We 数的通用稳健算法和全热力学闭合需单独论证，不直接宣称一次升级完成。

## 工作拆解与涉及文件

1. `moldingViscoelastic`：比较精确线性松弛、隐式或受控子步；子步有硬上限。
2. `fvModels/viscoelasticStress`：定义应力输运变量、通量、边界及相权重，
   明确 PIMPLE 多次调用时的更新时间层；read() 实际更新或拒绝不可热更新项。
3. 保留 `viscoelasticFeedback` 固定期望；新增零流动松弛、均匀平移应力包、
   两相界面和入口应力的小基准。
4. 核对重启与周期重置对 tau 的初态/oldTime 状态恢复。

## 验收标准

零流动松弛单调、有界并收敛；均匀平移的应力包与独立输运参考一致；气相
处理符合文档；关闭动量反馈仍触发原断言。每个载体最多几百单元，长时高 We
与多相矩阵走 CI，新增容差有时间/网格依据。

共享 DoD 仍适用：构建无新增告警、相应最小测试及完整 CI/契约验收，记录
提交哈希与取证口径后再标 done。遵循 `../diagnostics.md`。

## 风险与缓解

对流项和相权重直接影响应力的量纲/守恒形式；不能简单在现有源项外乘
alpha 就宣称完成。粘弹性储能不能全部当热耗散，和 067 协同设计。

## 实施记录 2026-09-15

`moldingViscoelastic::advance()` 已加入材料时间限步：单个 RK2 子步不超过
`0.1 lambda`，优先保证应力反馈精度，不改变本构方程，只细分积分区间。均匀剪切输运、相区权重、
重启/周期状态和完整稳定性对照仍待后续小用例及 CI 验收。

`viscoelasticStress` 增加 `transportStress` 可选开关；开启后先按 `phi` 对 tau
做显式守恒对流，再执行本构积分。默认关闭，保持旧案例结果兼容。
