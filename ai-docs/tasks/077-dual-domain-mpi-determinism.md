# 077：Dual Domain MPI 分区、确定性归约与一致性

- 状态：planned
- 优先级：P1
- 依赖：073 全局 ID；075、076 可运行
- 来源：2026-09-15 用户 Dual Domain / Kairos 扩展需求

## 设计与文件规划

新增 `src/dualDomainFoam/parallel/`、分区/重构脚本及
`tests/dualDomain/` serial/MPI fixtures。分配三角形与厚度积分计算，
不把每个 rank 重复完整串行求解冒充 MPI。

1. 全局稳定 ID 定义 owner/ghost、共享边通量唯一计算和通信顺序；
   用非均匀分区、空局部边界及跨 rank 浇口检查通信契约。
2. 厚度节点按固定 ID 顺序累加；质量、能量、压力积分采用可复现累加器
   或稳定全局顺序算法。仅补偿求和不能自动保证跨 rank 数逐位一致。
3. Krylov 点积、收敛判断、max/min 并列 ID、全局 CFL 与事件时间同样纳入
   确定性设计；不能仅让最终日志的 sum 确定而求解路径仍漂移。
4. 冻结保证范围：相同输入、提交、OF14/编译器/精度与硬件环境下，
   rank 数/分解改变不改变核心指标。比较未经舍入的结构化数值；
   跨架构单列容差，不宣称跨平台逐位一致。若无法实现，记录未满足需求。
5. 输入错误/局部数值失败全局传播、有限超时退出；重构输出不丢单元或重复计数。

## 验收标准

- np1/2/4、至少两种分区和重复运行，完整核心指标与质量/能量预算确定一致；
  场值按全局 ID 对齐比较，并报告最大差异，不能只比较打印后的低精度值。
- 非对称温度、厚度跳跃、VP 边界事件及负例均覆盖，所有 rank 正常退出，
  MPI 失败不留下孤儿进程。
- 原始串行/MPI 日志、环境、分区摘要、节点/面数、步数、内存和墙钟保存。
  性能记录区分求解/归约/I/O；不通过取消确定性或放宽精度获取加速。
- 同一库只加载一份，打包与真实命令启动回归通过。完整矩阵交 079 nightly。
