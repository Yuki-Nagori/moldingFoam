# 067：完整能量账目与耦合精度约束

- 状态：in-progress
- 优先级：P2
- 依赖：063 / 001 / 007 / 024 / 035
- 来源：2026-09-15 整体复核；承接 063 以外的明确剩余项

## 背景与现状

增强黏度生热已在 063 用倍率断言覆盖；仍无完整边界热量、内能、机械功
和数值裁剪预算。温度被硬裁到 250–3000 K，未报告裁剪能量。
Tait 表观潜热与结晶动力学潜热同时启用时，需要明确材料潜热是否重复计入。

## 目标与非目标

建立可解释的能量账目和耦合开关契约，区分物理热源、模型储能与数值修正。
不改变默认温度范围或潜热配置来让预算看上去通过。

## 工作拆解与涉及文件

1. `moldingFoam::thermophysicalPredictor()`：记录裁剪单元数及焓/内能变化，
   约定使用哪个时间层的黏度、chi、a、rho；复核 PIMPLE 外迭代一致性。
2. `hMeltThermo` / `moldingCrystallization`：写清潜热组合规则，给双开配置
   加独立量热基准或明确禁止条件。
3. 给 Couette、封闭冷却、CHT 增加边界积分与能量变化对拍，分别量化
   压力功、耗散、潜热及裁剪项。
4. 将不平衡阈值与 dt/网格相关联，输出维度、时刻及材料参数。

## 验收标准

无热源绝热箱、定剪切生热、单一潜热及约定的组合模式各自闭合；人工触发
裁剪会产生非零修正预算且不会被当成物理源。固定期望关掉热源实现必须失败。
只用单元/小薄层载体本地验证，完整 CHT 周期留 CI。

共享 DoD 仍适用：构建无新增告警、相应最小测试及完整 CI/契约验收，记录
提交哈希与取证口径后再标 done。遵循 `../diagnostics.md`。

## 风险与缓解

能量变量的显热/总内能定义必须和上游离散一致；不重复添加压力功或应力功。
实现预算前不能仅凭温度单调或质量残差声称能量守恒。

不计入物理热源。默认 250–3000 K 范围保持不变；边界热量、压力功、潜热组合
现由 opt-in `energyBudget` 账目输出，完整能量残差仍待后续小载体验收。

### 边界热量/压力功账目实现 2026-09-15

新增可选 `energyBudget true;` 诊断。每个 `massBudgetInterval` 步对温度方程
使用的 `TEqn.flux()` 做一次非 processor 边界全局归约，同时对同一绝对通量
离散的 `div(phi,U)·p` 做体积分压力功（乘实际 `deltaT`）。潜热和黏性耗散
继续分别报告；温度 safety clamp 明确排除在物理源项之外。默认关闭，避免改变
既有算例和常规步开销。

of14 增量 `xmake` 与 `xmake run test` 全部通过；本地未开启大网格账目运行，
因此边界通量与压力功的完整闭合残差仍交由 nightly case 验证。
