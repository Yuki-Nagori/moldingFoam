# 039 — 汽蚀空洞的闭锁约束与标定（033 跟进）

- 状态：planned
- 优先级：P1
- 依赖：033（上游 `VoFCavitation` 压力钉已达成）
- 预估规模：1–2 天

## 1. 背景与现状

033 用上游 `compressible::VoFCavitation`（SchnerrSauer）把密封冷却的
压力钉在 pSat（实测 1000–1008 Pa，原张力路径 −4.2 MPa），并开洞
~2.95%（`tests/cases/voidCavitation`，22/22 全绿）。遗留两点：

1. **闭锁量偏差**：018a 体密度闭锁 / 0D PVT 闭锁预测 ~4%，模型给
   ~2.95%（瞬态滞后）；且模型为相变传质，空洞量取决于 Cv/Cc 与瞬态
   （平衡退化——任意空洞量在 p=pSat 都是稳态）；
2. **标定窗口窄且对重建敏感**：Cv=0.1/Cc=10 在早期构建稳定，重建后
   失稳；Cv=0.05/Cc=10 + **物理导热材料**（Pr 由 k=0.18 反算）后连续
   两次稳定（void 1.6%、p 钉 1000 Pa）；Cv=0.02 反而不稳——窗口不
   规则，需按本任务方案 A/B 从源头（闭锁约束）解决。

## 2. 目标

1. 空洞体积与 PVT 闭锁一致（±10%，至少 3 个工况）；
2. 稳定性不依赖窄系数窗口（Cv ∈ [0.05, 0.3] 均可跑）；
3. 缺省不影响既有用例（新增能力显式开启）。

非目标：替换压力钉机制（已达成，保留）。

## 3. 技术方案（候选，按优先级）

- **A. 闭锁约束源项（推荐，物理最正）**：新增自注册 fvModel
  `moldingVoidClosure`，在 α/p 方程上与汽蚀源叠加：以闭锁状态
  （等容路径 `p_iso = pMeltIso(rho,T)`、`phi_closure = max(0,
  1 - rho/rho(pv,T))`）计算**目标空洞体积**，当模型空洞超过闭锁时
  抑制蒸发并增强冷凝（按 `phi_model - phi_closure` 反馈）；
  实现参考上游 `VoFCavitation` 的隐式线性化（`mDot12Alpha` /
  `mDot12P`，压力方程 `fvm::Sp` 模式）；
- **B. 等容驱动源**：直接用体积守恒给源 `S_alpha ∝ -(1/rho)d(rho)/dt`
  （冷却收缩率驱动开洞），冷凝系数保持高以吸收过冲——避开退化平衡，
  但需处理与压力钉的隐式耦合；
- **C. 系数自适应限幅（最简，先试）**：把 Cv/Cc 按
  `|p - pSat|/pSat` 或空洞占比限幅，扩展稳定窗口——若 A/B 成本高，
  先交付 C 并记录精度。

## 4. 工作拆解

1. Cv 扫描矩阵（0.05/0.1/0.2/0.3/0.5 × Cc 1/10/100），记录失稳边界与
   空洞量；
2. 方案 C 快试（限幅实现 + 复测）；
3. 不足则方案 A 的 fvModel（含 α 与 p 两个方程的源、隐式项）；
4. 验证器扩展：与 0D 闭锁对拍（`scripts/void_cooling.py`）+ 跨工况
   （几何/冷却速率/密封压力）；
5. README 契约（v1.2x）+ 033/039 文档更新。

## 5. 验收标准（DoD）

- 空洞 vs 闭锁 ±10%（≥3 工况）；
- Cv ∈ [0.05, 0.3] 稳定（无 NaN、压力仍钉在 pSat）；
- 模型测试 + 全部求解器用例（22+）全绿；
- 契约与文档同步。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 源项与压力方程隐式耦合复杂 | 照抄上游 VoFCavitation 的线性化模式；先显式后隐式 |
| 闭锁反馈引起振荡 | 欠松弛 + 限幅；必要时方案 B |
| 上游模型版本差异 | 契约固定 `compressible::VoFCavitation` 类型名与键 |
