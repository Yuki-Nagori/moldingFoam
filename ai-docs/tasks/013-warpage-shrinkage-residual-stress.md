# 013 — 翘曲/收缩/残余应力（结构耦合，超出当前模块范围）

- 状态：deferred（超出 moldingFoam 单模块范围，需结构求解器配合；
  已拆分为 013a（PVT 一致收缩/残余应力指标，done）与 013b（结构耦合
  翘曲，planned））
- 优先级：P3
- 依赖：001/002/008/012
- 预估规模：数周起

## 1. 背景与现状

当前求解器止于充填/保压/冷却顶出，输出温度场即可，但不预测制品的
收缩率、翘曲与残余应力——这是注塑 CAE 的下一步价值点。需要：

- 与 PVT 一致的热力学路径（比容历史 → 自由收缩）；
- 结构平衡（线弹性/粘弹性、温度相关模量）；
- 脱模边界条件（约束释放后的自平衡）。

## 2. 目标与非目标

### 目标
1. 从温度/压力历史计算体积收缩与各向异性收缩（流动/横向）；
2. 结构求解得到翘曲位移与残余应力场；
3. 与商用软件/文献结果对比验证。

### 非目标
- 非线性大变形、接触、疲劳；
- 在线闭环优化。

## 3. 技术方案（待评审）

- 路线：温度场热载荷 → `solidDisplacement` 模块求解热弹性/粘弹性；
- 残余应力来源：不均匀冷却 + 保压压力历史 + 层间收缩差；
- 采用 PVT 一致的自由应变 `ε_free(T,p)`，避免简单线膨胀近似。

## 4. 工作拆解

1. 文献/商用软件路径评审与基准选择；
2. 自由应变与粘弹性本构实现；
3. 结构模块集成（多区域/顺序耦合）；
4. 基准件（如平板/哑铃）翘曲对比；
5. 文档。

## 5. 验收标准（DoD）

- 基准件翘曲与文献/软件偏差在可接受范围（如 ±10%）；
- 残余应力定性分布正确；
- 不影响现有流动求解结果。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 材料粘弹性参数缺乏 | 先用热弹性 + 自由应变，逐步升级 |
| 与流动求解的单向/双向耦合复杂度 | 先顺序耦合 |
