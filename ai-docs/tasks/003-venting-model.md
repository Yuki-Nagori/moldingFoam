## 0. 评审结论（本次修订，先读）

0. **006 已完成的工作**：`moldingVentVelocity` / `moldingVentPressure`
   已实现排气口"只透气、遇熔体密封"，`moldingStage::ventSealed`
   由求解器按局部 `alpha.melt` 置位。
0.1 **选项 A（反压）已完成**：`ventOrifice` 准稳态孔口关系 + 边界参数
   `CdA`（缺省 0 = 全开，无背压）：`p_vent = p0 +
   sign(ṁ)·ṁ²/(2ρ·CdA²)`，`ṁ` 取当前 patch 质量通量（显式耦合，
   在 PIMPLE 校正内迭代收敛）。模型测试与临时受限排气流验证见
   第 5/6 节。可压缩/阻塞孔口扩展留作后续。
0.2 **选项 B（困气诊断）已完成**：`moldingDict` 可选
   `trapAirInterval`（步间隔，缺省 0 关闭）与 `trapAirAlpha`（缺省
   0.5）。求解器每 N 步标记空气单元，从开放排气口洪水填充连通域
   （跨处理器交换连通标记直到全局收敛），报告未连通空气的单元数/
   体积/质量/质量加权压力与温度/最高温度/质心；排气口密封后全部
   残余空气计为困气。只读诊断，BFS 仅遍历空气单元。

1. **原方案的载体不成立**：`compressibleVoF` 只有**一个共享的
   `p`/`p_rgh` 场**，没有"air 相 p 场"。新边界条件必须挂在共享
   `p_rgh` 上，并用 patch 内的 `alpha.melt` 判断该面是在排气
   （空气接触）还是被熔体封闭。
2. **原等熵公式漏了体积项**：`p_vent = p0·(m_air0/m_air)^γ` 只考虑
   排出质量。注塑排气反压的主导机制是**腔体被熔体填充导致空气体积
   减小**（等熵压缩 dρ/ρ = dV/V），因此最低阶正确关系是
   `p_vent = p0·(ρ_air/ρ_air0)^γ`，其中 `ρ_air` 由腔内空气质量与
   空气体积 `V_air = V_total − V_melt` 决定。
3. **全局量不适合放进 BC**：边界条件在每次矩阵求值时被反复调用，
   在其中做 `gSum` 归约既慢又危险。推荐两条路线：
   - **A1（推荐起步）局部孔口 BC**：把 vent 当作有限流通面积的孔口，
     `ṁ = Cd·A·sqrt(2ρ·Δp)`（大压差用等熵孔口流量公式），背压随流量
     自然上升。全部本地量，并行天然一致，无需持久化状态；
   - **A2（集总状态，备选）**：与 `moldThermalState` 同模式，在
     `preSolve()` 里积分腔内空气质量并更新 vent 的参考压力；需要
     regIOobject 持久化与多周期语义。
4. **困气诊断（选项 B）**保持 function object + `regionSplit` 后处理，
   只报告不修改求解；演示 case 用"两端进胶、中部合拢困气"的几何。
   不要在每次求解迭代里做连通域标注。

## 1. 背景与现状

当前空气相以 `perfectGas` 建模、顶部 `vent` 为开放边界：填充时空气
自由排出，vent 处压力恒为参考压力。真实注塑的两个缺陷模式没有被
覆盖：

1. **排气反压**：排气通道有限，空气被压缩导致腔内背压上升，填充
   后期注射阻力增大；
2. **困气（air traps / dieseling）**：流前沿合拢处空气无法排出，
   被压缩到高压高温，造成短射、困气烧痕。

当前模型里 vent 是全开边界，与 vent 连通的区域不会憋压；完全封闭
区域（不连通 vent 的 cell zone）会因缺少压力参考而病态。

## 2. 目标与非目标

### 目标
1. 支持配置"排气受限"：vent 边界反压随空气压缩状态上升，可复现
   背压上升（选项 A）；
2. 支持困气区检测与压力/温度报告（诊断输出，选项 B）；
3. 契约字典可选启用（缺省关闭 = 现有开放 vent 行为）。

### 非目标
- 空气-熔体界面处气体溶解/渗透；
- 分型面几何级的排气槽建模（由 case 网格决定）；
- 分相压力场（需要上游求解器结构改动，超出模块覆写能力）。

## 3. 技术方案（修订）

### 选项 A1：局部孔口 vent 边界（推荐起步）

新 BC `ventingPressureFvPatchScalarField`（`0/p_rgh` 的 vent patch，
自注册、带 `write`/拷贝族，参照 `moldingPrghPressure` 的结构）：

- 参数：`p0`（环境压力）、`CdA`（有效流通面积，`Cd·A` [m²]）、
  `gamma`（等熵指数）、`T`（气体温度）；
- 空气接触时按孔口流量给出等效面通量，熔体接触时退化为
  `fixedFluxPressure`（不可压封闭）；
- 由孔口方程 `ṁ = CdA·p0/sqrt(RT)·Φ(p/p0)`（可压缩等熵孔口函数，
  含临界压比封顶）反解 patch 压力，流量通过边界通量进入压力方程；
- 可选 `ventReservoirVolume` 模拟排气总管容积，仍为本地量。

优点：无全局归约、无持久化、并行一致；缺点：需要认真推导
可压缩孔口通量与 `p_rgh` 方程的耦合线性化（`SuSp` 处理）。

### 选项 A2：集总反压状态（备选）

与 `moldThermalState` 同模式的求解器侧状态：每步由
`alpha1`/`rho2` 积分 `m_air`、`V_air`，按 `p_vent = p0(ρ/ρ0)^γ`
更新 vent 参考压力，写回 `p_rgh` 边界；状态写 `postProcessing/`
便于重启。实现更直观，但需要处理并行归约与多周期持久化。

### 选项 B：困气诊断

- `preSolve`/function object 每 N 步：对 `alpha.melt < 阈值` 的单元
  做 `regionSplit`，与 vent 连通域求差得到困气区；
- 报告体积、质量加权压力、最高温度与位置到 `postProcessing/`；
- 不修改求解（诊断优先；压力修正作为后续可选项）。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| `CdA` 很小时显式孔口耦合刚性强、可能振荡 | 参数下限检查 + 必要时对 `refValue` 欠松弛；先用演示变体标定稳定范围 |
| 可压缩/阻塞孔口（大压差） | 当前为不可压缩孔口律，低压比适用；阻塞扩展留作后续 |
| 并行 patch 通量归约 | `gSum` 只用本地面量，契约并行回归通过 |
| 困气连通域标注开销 | 后处理 function object/求解器钩子，每 N 步一次（选项 B） |
| 契约 case 无困气，收益不确定 | 选项 B 用专门演示 case 评估 |
