# 049 — 外部精度标定 MVP（公开 benchmark 对拍）

- 状态：done（2026-09-14：1D 润滑参照落地在 fountainFlow 用例内，实测 −3.09%；文献/实验数据检索留作后续可选）
- 优先级：P2
- 依赖：017（基准验证范围）、020（喷泉流）
- 预估规模：1–2 天
- 来源：046 后续评估——017 明确「验证只有函数级 modelTests 与自洽的
  契约 case，没有与实验或商用软件（Moldflow/Moldex3D）的对比，工程
  精度未标定」，因无授权不在当时范围

## 1. 背景与现状

现有对拍全部是解析解/文献解析/自洽：

- 解析类：Couette 4.1e-4、滑移 3.3e-9、Stefan 0.25%、喷泉流 1.64%、
  Timoshenko 4.2–5.5%、PVT 1.6e-6、流道 0.93% 等；
- 自洽类：契约 case 守恒 9.38e-4、CHT 界面 0.19%（对拍对象是自写的
  一维 FD 参考）；
- **工程精度没有外部参照**：注塑行业真正关心的是充填压力/锁模力/
  短射长度/收缩值的绝对偏差，这些只在与实验或商用解算器比较时才有
  意义。

## 2. 目标

用**公开可引用**的数据源补一条外部参照链，给出一项（最好两项）独立
对拍的偏差量级：

1. **Hele-Shaw 一维压力降**（注塑行业标准近似，公开公式）：
   矩形薄板恒流充填，`p_gate` 随充填长度的解析关系
   （`p ∝ 12μQ/(w h³) · L` 形式，含 CrossWlf 剪切变稀修正）；
   对拍点：契约几何或专门薄板 case 的 `p_gate` 时间序列；
2. **公开实验/文献数据**（二选一，需检索并注明来源与许可）：
   - 短射长度 vs 注射压力/温度的公开数据集；
   - 薄壁板充填压力的文献曲线（数字化取点）；
3. 输出「外部参照」小节：数据来源、对拍量、偏差、以及**局限声明**
   （几何简化、材料参数来自何处、哪一段可外推）。

## 3. 技术方案

- 优先做 Hele-Shaw 一维解析：它虽然不是实验，但**独立于本求解器的
  数值格式**（行业工程口径），且无需外部授权，成本最低；
- 对拍量选择：`p_gate(t)`（已有 `moldingPrghPressure` 边界与
  `massBudget` 诊断，且契约 case 的 `p_gate` 跟随已打印）；
- 材料模型用契约的 CrossWlf/Tait，报告里显式说明「剪切变稀下解析式
  需按局部剪切率积分，本项用厚度平均等效黏度近似」这一层近似；
- 若找到合适的公开实验数据，另建 `validation/<name>` case 走
  `run-validation.sh` + 一个 `verify-*.py`。

## 3a. 已落地（2026-09-14）

在 `tests/cases/fountainFlow` 的验证器内新增**发展段注入压力梯度 vs 1D
润滑（Hele-Shaw/平行板）参考**：

- 参考式：`dp/dx = 12 mu u_mean/h^2`，`mu = rho(T,p)·nu`（rho 取该 case
  的 Tait、nu 取 powerLaw 字典），与求解器离散无关；
- 采样：该 case 已用于剖面检查的**发展段测站 x = 5.25 mm**（距入口
  ~1.3h、距前沿 ~3.7h）；
- 实测：`dp/dx = -6.781e+05 Pa/m` vs 参考 `-6.996e+05 Pa/m` →
  **偏差 −3.09%**（阈值 10%）；
- **残差被解析解释**：8 层网格下 no-slip 半格边界条件的离散壁面剪切
  使流量偏大，理论值 −3.13%（本任务内独立推导），实测 −3.09% —— 即
  偏差来自离散而非模型。

**被否决的口径**：全局 `p_gate(L)` 斜率拟合给出 −15% 的偏差，但场诊断
显示 dp/dx 在熔体发展段（x≈4–9 mm）与参考差 −2.9%、而在前沿后 ~2h 的
喷泉回流区只有一半——全局拟合被喷泉区污染。因此检查改为局部发展段
梯度，并把喷嘴/入口单元排除在外。

**未做的可选第 2 项**：公开实验/文献数据的检索与建 case（DoD 允许
「一项」即可）；若后续需要工程绝对精度参照，另开任务。

## 4. 工作拆解

1. 推导/实现 Hele-Shaw 参照脚本（半天）；
2. 在契约几何（或专门薄板）上跑一次并出偏差（半天）；
3. 检索并评估 1–2 个公开数据源，选一个建 case（可选，1 天）；
4. 文档：README 新增「外部参照」小节 + 本任务状态。

## 5. 验收标准（DoD）

- 至少一项外部参照的对拍数字（偏差量级 + 曲线/散点）；
- 数据来源可引用、局限写清；
- 若某项因数据不可得而放弃，记录检索范围与放弃理由（替代「无授权」
  这一笼统说法）。

## 6. 风险与缓解

- 公开实验数据常有材料/几何不完整 → 优先选参数齐全的薄板类；不够
  齐全时降级为「量级对拍」并明确标注；
- Hele-Shaw 近似在浇口附近不成立 → 对拍区间取远离浇口的
  `L/h > 10` 段，并在报告中标出偏离段。
