## 1. 复测结果与判读

| 阶段 | C（873 cm³）表现 | 机制 |
|------|------------------|------|
| v0.2.3 原始（坏材料 Pr=4） | 切换 t=4.3404 s（p_gate 5.44 MPa）→ 4.3463 s non-finite | **冻死短射**：故障前三帧实测熔体（α>0.5）≈100% 低于 418 K，|U| 峰值在入口单元 11→31→192 m/s；k=mu·Cp/Pr=62500 W/mK（比物理值高 5 个数量级） |
| 仅修 k（Pr 由导热表反算，k=0.18） | 切换提前至 3.9184 s（填充变快、守卫全程静默=无熔体低于 418 K）→ 切换后 2.5 ms non-finite（Co 1.63e8） | **保压阶跃**（与 B 同源）：升压时间尺度不足 |
| 修 k + ramp 0.2 s | **跑到 endTime 8 s**，Phase-1 0.9957，保压闸口 57.5→51.8 MPa 平滑跟随，reconstructPar exit=0 | 验证成立 |
| 点浇口盒（修 k 后） | 通过，填充 0.9947 | — |

**更正**：我们此前「更长 ramp 对 C 不会解决」的预期基于修材料**前**的
冻结态；材料修复后 C 回到保压阶跃类，ramp 时长必须随过程时间尺度放大。

## 2. 求解器侧已落地（提交 `19cee9f`）

1. **`packing.pressureRamp` 缺省改为自适应**：不写该键时取「切换时刻
   的 5%，夹 [0.05, 0.5] s」；显式写值（含 0=立即阶跃）行为不变。
   - C（切换 3.92 s）→ 0.196 s，与 Kairos 手调的 0.2 s 一致；
   - 大件无需再手调；小件仍走 0.05 s 下限。
2. **启动回显补充**（消除误判）：
   ```
   pressureRamp          = auto (5% of the switch time, clamped [0.05, 0.5] s)
   gateFreezeTemperature = -4.5036e+15 (gate seal; -great = disabled)
   freezeOffTemperature  = 418 / disabled
   freezeOffFraction     = 0.01
   ```
3. **回归用例材料修正**：`tests/cases/voidCavitation` 同样继承了
   `Pr=4`（k=62500），已改物理导热（Pr=1.39e6 → k=0.18）并把汽蚀系数
   调至稳健窗口（Cv 0.05/Cc 10）：连续两次运行稳定、p 钉 999.9–1000 Pa、
   void 1.6%（22/22 套件全绿）。
4. 相关：v0.2.2→v0.2.3 的冻死守卫（`freezeOffTemperature`/
   `freezeOffFraction`）与保压 ramp 已交付；B 的通过即 ramp 生效证据。
