- 状态：done（2026-09-10：本构 + 启动/松弛/N1/振荡解析验证 + fvModel 动量耦合；tau 随流输运与多模谱为增强）
- 优先级：P2
- 依赖：001/007
- 预估规模：1–2 周

验收记录（第一阶段：本构模型 + 解析验证）：

- `Foam::moldingViscoelastic`：单模上随体 Maxwell（UCM）+ 可选
  Giesekus 二次迁移项
  `λDτ/Dt = λ(Lτ+τLᵀ) + 2η₀D − (λα/η₀)τ·τ − τ`，局部（均匀流动）
  演化，RK2 步进；参数 `relaxationTime`/`zeroShearViscosity`/
  可选的 `mobilityFactor`；
- model tests（解析对拍）：
  - UCM 启动剪切 `τ_xy = η₀γ̇(1−e^(−t/λ))`（rtol 1e-4）；
  - 松弛 `τ_xy = τ₀e^(−t/λ)`（rtol 1e-4）；
  - 稳态第一法向应力差 `N1 = 2η₀λγ̇²`（rtol 1e-3）；
  - Giesekus：η(0.1)=990 → η(1)=618 Pa·s 剪切变稀、N1>0；
  - 无流动 τ 保持 0；
- 动量方程耦合（第二阶段）：自注册 fvModel `viscoelasticStress`
  （`constant/fvModels` 选择）：持有 `tau` 场、逐步推进本构（PIMPLE
  校正器内以时间索引防过积分）并向动量方程加 `div(tau)`；用例
  `tests/cases/viscoelasticFlow` 剪切通道中 max|tau_xy|=1.54e5 Pa、
  运行稳定；
- 振荡剪切（解析补充）：小振幅 UCM 稳态 `|tau_xy| =
  eta0 gammadot0/sqrt(1+(lambda omega)^2)` 对拍 rtol 1e-2；
- `xmake run test-solver` 17 用例全绿；缺省不选 fvModel 时牛顿行为不变。

## 1. 背景与现状

当前 CrossWlf 为广义牛顿（无弹性）。聚合物熔体的弹性（法向应力、
挤出胀大、应力松弛）影响保压/翘曲/残余应力，需要粘弹性本构。

## 2. 目标与非目标

### 目标

1. 粘弹性本构（如 Giesekus/PTT）实现；
2. 启动剪切/振荡剪切基准验证；
3. 与流动耦合稳定；
4. 支撑 022/023 的残余应力。

### 非目标

- 多模式谱的完整标定。

## 3. 技术方案

- 在 `momentumTransport` 框架内自注册粘弹性模型（模块内）；
- 构型张量/应力输运方程；
- 基准：启动剪切应力增长、振荡剪切 G′/G″。

## 4. 工作拆解

1. 本构选型与稳定化；
2. 实现与基准；
3. 与流动耦合回归；
4. 文档。

## 5. 验收标准（DoD）
