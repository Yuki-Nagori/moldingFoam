## 2. 优先修复项

### R1 / P1：hybrid 纤维闭合的线性/二次权重反了（S+A）

- 位置：`src/moldingFoam/moldingFiberOrientation.C`，
  `moldingFiberOrientation::AcolonD()`。
- 代码令 `f = 1 - 27 det(a)`，却返回 `f*linear + (1-f)*quadratic`。
  对应闭合应为 `(1-f)*linear + f*quadratic`。
- 各向同性 `a=I/3` 时应取线性闭合，完全定向时应取二次闭合，当前恰好反过来。
  简单剪切率 1/s、lambda=0.8、初始各向同性时，当前 `da_xy/dt=0.2666667`，
  精确各向同性四阶矩给 `0.16`，初始斜率高 **66.7%**。这不是整场误差估计。
- `tests/modelTests.C` 的纤维配置都是 quadratic；本次扫描 tests/validation
  没有 hybrid 命中。Jeffery 对拍不能覆盖此分支。
- 最小验收：各向同性与秩一两种端点的四阶矩收缩；然后做固定期望的
  hybrid 模型断言，不能用同一错误实现生成期望。
- 公式交叉核对：[Abaqus 官方闭合公式](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-meanfieldhomogenization.htm)。

### R2 / P1：增强黏度没有进入黏性生热（S）

- 位置：`src/viscosityModels/CrossWlf/CrossWlf.C` 的 `CrossWlf::nu()`、
  `CrossWlf::eta()`；`moldingFoam::viscousDissipationSource()`。
- 动量用的内部场黏度乘了 Lipscomb 因子和 `crystallinityFactor`；生热源
  调用的标量 `eta()` 只返回基础 `etaValue()`，没有这些增强。
- 同一速度梯度下，动量应力与耗散不一致。例：结晶因子为 2，单独启用
  该增强时生热仍按基础黏度计算，只有相应黏性耗散的 1/2。
- `CrossWlf::nu()` 的边界场也只计算基础黏度，需一起审查壁面力/通量的一致性。
  具体壁面离散影响需要小用例确认，不能直接按内部因子推整件误差。
- 现有 `anisoViscosity` 虽开启生热，壁面力断言不能证明热源闭环；
  `crystallinityViscosity` 关闭生热。
- 建议共享最终有效黏度/应力计算；以定剪切、固定 chi/a 的少量单元检查
  机械功与热源积分。粘弹性额外应力的储能/耗散应另立热力学口径。

### R3 / P1：多排气口被一个全局标志同时封死（S）

- 位置：`moldingFoam::preSolve()`、`moldingStage::sealVent()`，以及
  `moldingVentVelocityFvPatchVectorField::updateCoeffs()` 和
  `moldingVentPressureFvPatchScalarField::updateCoeffs()`。
- 任一排气 patch 的任一面达到 alpha 阈值就设置唯一 `ventSealed_`；
  所有排气边界随后读取同一标志。尚未到达熔体的另一出口也会封闭。
- 对不对称填充/多型腔会提前制造困气并改变压力及 V/P 触发；即使只有
  一个大 patch，也采用整片关闭语义，不是逐面润湿关闭。
- 建议至少支持逐 patch 密封并持久化。最小验证用两个出口，仅让一个
  接触熔体，检查另一个仍排气；串行通过后由 CI 做小 np2 对照。

### R4 / P1：多周期重启会把中途解当作下一周期初态（S）

- 位置：`moldingFoam` 构造函数的 `cycle_(1)` 和初场快照；`resetCycle()`。
- 所有 Initial 快照从当前已加载场复制、NO_READ/NO_WRITE；latestTime
  重启后保存的是中途的 alpha/U/T/p，后续 reset 就恢复到这个中途状态。
  周期计数也从 1 重来，会多运行周期。
- `resetCycle()` 没有清空质量预算历史；启用 massBudget 时会把卸料/reset
  引起的质量跳变计成守恒残差，启用 massFixGlobal 时还会用上一周期预算
  修正新周期密度。额外 `tau` 同样不在重置列表内。
- 建议分开持久化周期编号、周期起点和真正初态，逐项定义诊断与材料历史
  的重置策略。用“两周期、在第一周期中段重启”的小用例比对下一周期
  初态、最终周期编号；质量修正开关另做单变量对照。
- 061 的单周期导热/阶段状态对拍没有覆盖以上组合，不否定其原验收结果。

### R5 / P2：汽蚀闭锁的参考密度不持久化（S）

- 位置：`src/moldingFoam/fvModels/moldingVoidClosure/moldingVoidClosure.C`，
  构造函数、`evaporationLimit()`。
- `rhoRef_` 是普通数组，重启时全零，空洞已存在时重新捕获当前混合密度。
  当前值一般不等于首次到达饱和压力时保存的参考值；
  `max(0,1-rhoRef/rho1)` 的历史基准因此发生变化。
- 应将参考密度与有效标记随场保存/映射；在空洞已经发展且密度已变化的
  时刻分段对拍。不要只在 onset 前重启，否则测不到此缺口。

### R6 / P2：并行 alpha 通量诊断重复全局求和（S+A）

- 位置：`moldingFoam::postSolve()` 的 `budgetPrint` 分支。
- `patchAlphaFlux=gSum(...)` 已是全局量，各 rank 累加后又对 fluxAlpha
  做 `reduce(sumOp)`，导致打印的 alpha 通量及 alpha/vol 比值乘以进程数。
- 四 rank 局部值 1/2/3/4：正确总和 10，当前算法得到 40；串行为 1 倍。
- 影响诊断，不影响该函数独立计算的 flux/m 或质量修正残差；勿据此
  宣称现有契约质量误差也是 4 倍。
- 删除重复归约，给 `parallelMassBudget` 增加同物理时刻串并行通量断言。

### R7 / P2：各向异性热导允许变成负值（S+A）

- 位置：`moldingFoam` 读取 conductivityAnisotropy 及
  `thermophysicalPredictor()` 中 `I + beta*(a-I/3)`。
- 参数无范围检查。合法取向 `a=diag(1,0,0)`、beta=4 时，热导倍率特征值
  为 `(3.6667,-0.3333,-0.3333)`，两个方向变成反扩散。
- 对所有合法二阶取向张量保证正定的简单范围为 `-1.5 < beta < 3`；
  也可直接检查实际热导张量的最小特征值。a 的 RK2 更新仅归一化迹，
  不保证任意时间步下半正定，不能仅靠参数范围替代取向有界性控制。
- 最小验收：合法端点 + 越界字典拒绝 + 大剪切增量下取向特征值检查。

## 3. 尚需小求解器实验的精度边界

1. **粘弹性输运与稳定性**：`viscoelasticStress::addSup()` 仅局部更新 tau，
   无对流项、无熔体相权重；适合局部/均匀剪切核验证，不能据此证明非均匀
   充填中的应力历史输运正确。`moldingViscoelastic::advance()` 是显式 RK2：
   零速度梯度、mobilityFactor=0 时，dt/lambda=3 的放大因子为 2.5，
   精确松弛为 exp(-3)=0.049787。现有 Courant 限步不等于材料松弛限步；
   优先做单元松弛测试，再决定子步/隐式/指数更新。
2. **周期时间语义**：forcedSwitchTime、入口 flowRate profile、runner 阀时序
   使用绝对时间；`resetCycle()` 不重置时钟。第二周期可能立刻满足首周期
   switchTime，阀门也可能一直关闭。若本意为全局时间表，应明确文档；
   若要求工艺重复，应增加 cycleStartTime，保压表已使用切换相对时间。
3. **Tait 负压守卫不完整**：`Tait::blendedDerivs()` 对 log 自变量截断，
   导数仍除以原始 `B+p`。p=-B 时仍可除零，p<-B 时与截断后的函数导数
   不一致；且两分支无条件求值，非活跃分支也可能触发 FPE。应明确模型
   有效域、越界拒绝/正则化及一致导数，以有限差分作最小验证。
4. **能量误差不可只用质量指标替代**：温度被硬裁到 250–3000 K，但没有
   输出裁剪能量；开启多重潜热机制时也需检查是否重复计入同一材料潜热。
   先增加裁剪次数/能量积分、边界热量+内能+耗散账目，再谈放松容差。
5. **流道非线性求解**：`solveTree()` 到 500 次迭代后静默返回，未报告是否
   达到 `1e-14*Q` 条件。结果可能有限但不收敛；需记录迭代数和压力/流量
   残差，极端剪切变稀/不对称热流道用小网络对拍。

## 5. 效率与代码质量：建议顺序

1. **按需分配周期快照**：当前 nCycles=1 也复制 alpha1/alpha2/U/T/p/p_rgh，
   仅内部 double 数据即 8 个标量分量，约 64 bytes/cell（百万单元约
   64 MB 十进制，未计边界及容器）；这是代码推算，不是 RSS 实测。
2. **共享网络一次求解结果**：每个 gateFlow/gateTemperature/pressureDrop
   查询都重新 solveTree。先统一 Q/t/字典版本与网格阶段，再缓存所有叶子
   流量/温度/压降；不可只按 timeIndex 缓存，PIMPLE 内 Q 可能改变。
3. **共享同状态下的梯度与有效黏度**：取向、黏度、生热、粘弹源重复求
   grad(U)。以修复 R2 为契机消除重复场构造，限定缓存失效条件。
4. **减少纯诊断的内存流量**：massBudget 每步复制 alpha/rho/p 三个全场；
   若需打印前一步差分，只在相应采样前保留快照，必须保持原取数口径。
   去掉 R6 的重复通信也是直接收益。
5. **拆分主类职责**：主求解器集成状态机、诊断、材料输运、热源与重载。
   可逐项提取生命周期组件；建立“初始化/每步更新/写出/重启/周期重置”
   状态表，比继续增加独立 bool 更能预防本次 R4/R5 类问题。
6. **参数读取统一校验**：例如 moldingStage 构造拒绝负 gateSealRamp，
   read() 却不作相同检查；viscoelasticStress::read() 无实际更新。
   区分可热更新参数和需重启参数，并保持构造/read 的拒绝语义一致。
7. **测试工具维护**：run-solver-tests 的预期失败分支 continue 前不清理
   临时目录，串行求解没有 timeout；并行前删除串行工作目录会丢失原始
   失败日志。优先保留失败证据并限定运行时间，避免失败吞掉整套机时。

不建议未取证就继续降低 alpha 子循环/修正遍数或扩大 dt。现有文档已记录
多项阴性；任何新优化均需同会话、同物理时刻、单变量，先核物理再计墙钟。
