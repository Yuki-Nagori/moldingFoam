# 019 — 模具三维共轭传热（008 落地）

- 状态：planned
- 优先级：P0
- 依赖：008/002
- 预估规模：1–2 周

## 1. 背景与现状

008 已落地路线 A 的最小可用版：`foamMultiRun` 双区域（cavity
`moldingFoam` + mold `solid`）、`coupledTemperature` 界面、静止导热
基准 0.19%/1.33%、VoF 充填能量守恒 0.24%，以及冷却水 1D 对流通道
BC。缺口是**完整注塑周期（保压/冷却/顶出）的三维 CHT 集成**：模具内
冷却水道的三维/网络等效、模温空间分布对充填的影响、多周期 CHT。

## 2. 目标与非目标

### 目标

1. 完整注塑周期的多区域 CHT（填充→保压→冷却→顶出）；
2. 冷却水道等效换热（模具内 3D 水区或 1D 网络）；
3. 与 002 集总模型在极限参数下一致；
4. 模温空间分布合理（浇口附近高于远端），多周期趋于周期稳态。

### 非目标

- 冷却水路几何自动生成；
- 模具热疲劳/热应力。

## 3. 技术方案

- 主线沿用路线 A（`foamMultiRun` + `regionSolvers`）；
- 冷却水道：模具区域内的 3D 水区（简单管道）或 008 的 1D 通道 BC
  施加于模具内壁；
- 周期重置与多区域耦合：模具 `solid` 保留温度、腔体重置流场；
- 用 008 的 `validation/moldCHT*` 扩展为周期 case。

## 4. 工作拆解

1. 多区域完整周期 case（含保压/冷却/顶出）；
2. 模具冷却水道（3D 水区或 1D 网络）实现与验证；
3. 与 002 集总极限对照；
4. 多周期模温稳态；
5. CI 夜间回归与文档。

## 5. 验收标准（DoD）

- 与 002 在极限参数（无梯度、均匀水路）下一致（rtol < 1e-3）；
- 模温分布定性正确（浇口附近高）；
- 周期稳态收敛；
- 现有 case 不劣化；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 多区域周期重置复杂 | 先单区域集总对照，再逐级多区域 |
| 3D 水区计算量大 | 先 1D 网络等效，模具粗网格 |
| 界面热阻/接触热阻 | 可选 wallResistance 已有 |
