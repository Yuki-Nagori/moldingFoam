- 状态：in-progress
- 优先级：P2
- 依赖：063 / 035 / 045 / 047 / 049

## 背景与现状

063 为新增回归补了有界执行和失败日志上传；通用 run-solver-tests 仍存在
预期失败分支临时目录未清理、串行无 timeout、串行失败后并行前删除证据的
问题。现有精度证据仍偏解析小基准；不能将两点阶估计或质量预算当成整件误差。

## 目标与非目标

先保证测试失败可被发现并保留证据，再建立目标量的空间/时间/参数不确定度
矩阵和外部定标任务入口。完整矩阵由 nightly 执行。

## 工作拆解与涉及文件

1. `scripts/run-solver-tests.sh`：串行与网格步骤有界；保留独立串/并行失败
   日志；清理成功临时目录；预期失败需要特定报错且不得被其他崩溃误满足。
2. Python 验证器核对 uniform/nonuniform、声明长度、所有分量有限性及
   同一物理时刻；用干净/故障合成数据自证，拒绝空样本与 NaN 漏检。
3. `.github/workflows/nightly.yml`：失败日志与关键输入 artifact 可追溯；
   063 的双架构/契约结果补入其验收记录，不另起重复完成任务。
4. `ai-docs/uncertainty.md`：针对压力、热通量、取向、翘曲分别制定三网格/
   三时间步研究；区分离散误差、材料定标误差与实验误差。

## 验收标准

模拟超时、网格失败、串行失败而并行成功均使 harness 正确失败并保留原始
证据；成功临时目录被清理。验证器对坏数据拒绝、对干净数据通过。
收敛矩阵脚本有资源预算与原始数值出处，不在本地跑全量；无外部数据时明确
记为未定标，不用自洽模拟结果替代实验。

共享 DoD 仍适用：构建无新增告警、相应最小测试及完整 CI/契约验收，记录
提交哈希与取证口径后再标 done。遵循 `../diagnostics.md`。

## 风险与缓解

判据强化可能暴露旧测试的假绿，必须先定位原因而非批量放宽门槛。
统计用例数不等于覆盖率；模型启用、结果响应、精度与失效灵敏度分开记录。

#### H1：先补齐 harness 的失败契约

代码复核仍见 `run-solver-tests.sh` 网格步骤缺少 timeout、进入并行分支前
删除串行工作目录的路径。按“准备→网格→分解→求解→验证→归档”逐阶段改造：

1. 串行和每种并行配置分配独立新鲜工作目录；失败后先保存再继续下一分支。
2. blockMesh、decomposePar、求解、重构及 verifier 都设置显式阶段预算；
   另设整行总预算，超时杀掉进程组并确认没有遗留子进程。
3. shell 捕获失败时显式处理退出码，避免 `if`/`||` 上下文使 `set -e`
   失效；任何前置阶段失败都不运行依赖它的后续阶段。
4. 预期失败必须匹配预先指定的错误类别与文本；timeout、signal、堆错误或
   空 expected 文本不能满足预期失败。保留原始 rc 及分类后的状态。
5. 成功默认清理大临时目录，但保留指标、有效输入及必要收敛历程；完整失败
   目录一直保留到归档成功。需要保留成功场文件时使用显式 artifact 策略。
6. 用可控替身进程故障注入：每阶段超时/非零、串行失败而并行成功、期望文本
   与崩溃同时出现、求解成功无指标、指标写到一半等；再跑一个 of14 干净小例。

退出：上述失败均令整组失败，能找到对应阶段的输入/日志，成功清理不会删除
其他分支证据。优先复用/扩展现有测试，不引入大规模求解才能验证的 harness 测试。

#### H2：区分“数据有效”“数值收敛”“精度通过”

结果结构拟升级为带 schema_version 的记录，至少包含：

- 身份：row_id、study_kind（joint / spatial / temporal / iterative）、
  source_commit、dirty_diff 摘要、环境与输入摘要、runner/verifier 版本。
- 配置：mesh/cells、dt 或迭代预算、实际步数、物理时刻或迭代标签、输出位置。
- 测量：quantity、unit、value、reference、reference_kind、error_definition、
  normalization（如 CHT 初始温差 127 K）、relative_error、threshold。
- 判定：solver_rc、verifier_rc、data_valid、converged、within_threshold、
  acceptance、reason；不适用的 converged 用显式 not_applicable，不能默认为 true。
- 资源：各阶段耗时、总墙钟、可取得的峰值 RSS、日志/场文件出处；缺值不填 0。

指标文件采用写临时文件后原子替换；每行读取前校验身份/数量/有限性/单位和
时刻，不接受别的行或旧运行的 JSON。将 collector 提取为可直接测试的入口。
无指标且求解 rc=0 时仍失败，原始 solver_rc 继续记录为 0，不混淆失败阶段。

探索模式可以记录收敛粗网格的超限误差；验收模式对指定中/细网格精度及所有
必需收敛判据硬失败。nightly 设置必需的验收 job，单独的探索 job 绿不能让
report 宣告任务通过。未收敛、未定标、不适用 GCI 分别记录，避免共用 PASS。

退出：合成数据覆盖三种状态的交叉组合，未知字段/缺失数据/旧 schema 的行为
明确；070 的结构收敛状态能直接进入表，原历史 TSV 保留不覆盖。

#### H3：按真实方程类型补齐独立矩阵和目标量

先对各载体字典及求解路径核实稳态/瞬态、固定/自适应 dt、源项时序及最终
输出，再冻结测量方案。结构载体的 steadyState/迭代语义按 070 执行。

| 研究 | 固定项 | 变化项 | 最低证据 |
|------|--------|--------|----------|
| 空间 | 材料/边界、同一物理截面或积分区域；时间/迭代误差充分小 | h、h/2、h/4 | 三行，实际各方向尺寸/网格比可追溯 |
| 瞬态时间 | 一个固定网格、同一物理终时与初态、同一采样窗 | dt、dt/2、dt/4 | 三行，禁用或严格记录自适应限步，终时确实对齐 |
| 结构迭代 | 固定网格及数值设置 | 预算/容差单变量 | 070 的稳态成立与目标量敏感性，不报物理时间阶 |
| 参数敏感性 | 已验收的离散/迭代配置 | 一个材料或边界参数 | 与离散误差分表；不能标实验定标 |

空间与时间两组三点可共享完全相同的锚点，因此通常为每个瞬态载体至少五个
唯一运行；先通过误差隔离复核再采用。共享锚点不等于网格×时间步的完整 3×3
析因矩阵；需要交互研究时才另排九点。空间研究中时间/迭代误差对 Q 的影响
目标为小于相邻网格差的 10%，否则先收紧背景误差预算，不能直接算阶。

| 量 | 落地流程 | 数据/物理判据 |
|----|----------|---------------|
| 压力 | 核实 `validation/fountainFlow` 的现有参照；固定入口/出口截面，以面积加权压降为主量，冻结采样时刻 | 单位 Pa、压力基准一致，参照适用区间明确；前沿位置变化影响单独记录 |
| 热通量 | `validation/moldCHT` 按真实多区域导热通量计算接口两侧面积积分及外边界积分 | 记录外法向符号、W 与 J 的区别、两侧闭合误差；不能用温度差直接冒充通量 |
| 取向 | 先从已有 fiber 输运用例挑选具有非零响应的薄层载体；无合适载体再新建小例 | 固定截面 a12 与张量不变量；trace/正定性检查。近各向同性时主方向不唯一，不能算角度误差 |
| 翘曲 | 消费 070 的三网格与固定物理截面测量 | 稳态和原 8% 精度门槛；旧口径同时保留便于对照 |

压力/热通量/取向的精度阈值须在各自实现批次前根据解析或独立参照误差预算
明确写入任务补记，并用故障对照证明灵敏度；未定阈值的行只能算探索，不能
算完成覆盖。CHT 现有平均温度仍保留为回归副量；一维离散参考也有自身网格/
时间误差，需独立加密证明参考误差足够小，不能与被测算例一起改期望使误差消失。

退出：四类目标量都有真实测量和适用判据；每行实际执行，有固定取数规则，
不存在只有 manifest、只有日志关键字或用温度替代热通量的覆盖声明。

#### H4：收敛分析与 GCI 的适用性检查

实现前核对权威方法定义并记录来源，分别实现“相对解析误差趋势”与“基于
三网格目标量差的 Richardson/GCI”，不能直接把两点解析误差塞进 GCI 公式。
检查网格比、同一可比 Q、单调性、可分辨的差值、观测阶有效性和渐近条件；
用已知阶的合成三点、非单调序列、零差/近零量及错误网格比自证。

不满足条件时输出 not_applicable 及原因，并列原始三点和误差范围。对已冻结
要求收敛的验收研究，条件未满足即研究失败；对探索性参数研究则保留记录。
旧 `uncertainty.md` 的两点粗估保留为历史，不沿用为本轮 GCI 验收证据。
