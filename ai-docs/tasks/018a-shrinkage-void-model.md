# 018a — 封冻后收缩空洞/负压建模（018 拆分）

- 状态：in-progress（阶段 1：PVT 指标 API + EOS 测试；阶段 2：`voidFraction` 场 + 密封冷却用例完成；阶段 3：PVT 精确对拍与质量守恒/张力限制待做）
- 优先级：P1
- 依赖：018
- 预估规模：1–2 周

## 1. 背景与现状

018 界定了 40 MPa 标定 case 的守恒窗口到闸口封冻为止（5.02e-4 < 1e-3）。
封冻后熔体继续冷却：定质量定容下 Tait 双域要求压力降到负值（张力）
才能保持密度，物理上表现为**收缩空洞**（p → 0/蒸气压，空穴形成）。
当前可压缩 VoF 无空洞/空化模型，压力停留在高压、密度被高估，表观
质量随冷却增长（hp40 实测 +2%/0.4 s，全周期守恒误差 4.5e-2）。

## 2. 目标

1. 封冻后封闭腔的冷却收缩可表示（压力衰减至 0/蒸气压或空洞）；
2. 熔体质量在封冻后严格守恒（空洞体积显式表示/诊断）；
3. 与 PVT 等压冷却/等容降压路径对拍；
4. 不影响现有 case（缺省不启用）。

## 3. 进展

### 阶段 1（2026-09-10，已完成）

- `moldingShrinkage` 新增可配置空化压力 `voidPressure`（默认 0 = 真空）
  与 `voidFraction(rho, rhoAtPv) = max(0, 1 − rho/rho(pv,T))`
   —— 封冻等容单元在 `rho(pv,T)` 超过密封密度时出现空洞；
- 单元测试（`tests/modelTests.C`，用真实 Tait 双域 EOS）：
  40 MPa/480 K 密封的等容体，480 K 时无空洞（被压缩），
  冷却到 350 K 时空洞分数 **0.0689**（与 PVT 一致，含过渡带共混），
  `rho ≥ rho(pv,T)` 时严格为 0；`voidPressure` 缺省/覆写均验证；
- 物理正确性：高温时密封密度 > rho(pv,T)（仍受压，无空洞），
  冷却使 rho(pv,T) 上升越过密封密度后才出现空洞。

### 阶段 2（2026-09-10，已完成）

- 求解器场：`shrinkage` 子字典开关 `voidFraction true` 时创建并写出
  `voidFraction` 场（默认关闭，现有 case 逐字节不变）；仅在
  `moldingStage.gateSealed()` 后计算，熔体单元（α>0.5）为
  `max(0, 1 − ρ/ρ_pv)`，其中 `ρ_pv ≈ ρ + ψ(pv − p)`（局部压缩系数
  一阶估计，p<pv 时为正）；循环重置归零；
- 新求解器用例 `tests/cases/voidFraction`（第 18 个）：初始即密封
  （浇口 460 K < gateFreeze 465 K，t=1.2e-5 s 封冻）、壁面 430 K
  冷却 1 s；空洞分数 **≈0.0499**（近均匀 0.043…0.050），全程稳定
  有界，无 018 的密封腔刚性振荡；
- 验证器 `scripts/verify-void-fraction.py`：封冻时刻、样本有界/低漂移、
  写出场与日志一致、近均匀；`xmake run test-solver` **18/18**；
- （阶段 2 的 ψ 线性化在阶段 3 已被精确 EOS 替换。）

### 阶段 3（2026-09-10，部分完成：精确 EOS）

- `voidFraction` 改用**精确 Tait** `rho(pv, T)`：从
  `constant/physicalProperties.<melt>` 的 `mixture` 子字典构造缓存的
  `Tait<specie>`（`voidEos_`），替代局部 ψ 线性化；
- 密封冷却用例：空洞分数由线性化的 5.0% 降为 **4.1%**（与 PVT 解析
  ≈3.7% 一致；剩余差为非均匀温度与封冻瞬时状态）；模型测试与
  18 个求解器用例全绿；
- **PVT 逐单元对拍（2026-09-10）**：验证器读取写出场
  （`alpha.melt`/`T.melt`/`rho`/`voidFraction`），用从
  `physicalProperties.melt` 解析的 Tait 系数在熔体单元上计算
  `1 − ρ/ρ_tait(pv,T)`，与 `voidFraction` 场逐单元一致到
  **1.6e-6**（156/160 单元）；
- **压力路径对拍（2026-09-10）**：验证器进一步检查密封熔体压力已
  降至空化压力以下（求解器 −4.230 MPa ≤ pv = 0）且等容压力路径与
  PVT 一致（PVT −4.280…−4.272 MPa，最大相对差 **1.16%**）；
- 待做（阶段 4）：张力限制（p 下限 pv、密度限制在 `rho(pv,T)`，
  需空洞体积/质量记账）、封冻后质量守恒 <1e-3（依赖 018 重构）。

## 4. 技术方案（候选）

- 空洞相：用 α 场表示空洞（降低 α_melt，压力限制在蒸气压 pv）；
- 张力限制：压力下限 pv，density 限制在 ρ(pv,T)；
- 或顺序收缩后处理：封冻后按 PVT 计算自由收缩与空洞体积（指标）。

## 5. 验收标准（DoD）

- 封冻后熔体质量守恒 <1e-3；
- 压力衰减到 0/蒸气压，空洞体积与 PVT 收缩一致；
- 现有 case 不劣化；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 空洞相引入新的界面刚性 | 先在小型密封腔实验上验证 |
| 压力下限与空化耦合复杂 | 先做后处理指标，再做场建模 |
