# 022 — 翘曲/收缩 MVP（013 分阶段落地）

- 状态：in-progress（2026-09-10：自由翘曲解析模型已落地并验证；结构求解/基准件对比待做）
- 优先级：P1
- 依赖：001–012
- 预估规模：2–4 周

验收记录（第一阶段：自由翘曲解析模型）：

- `Foam::moldingWarpage`：由厚度方向温度剖面计算自由膜应变与曲率
  `eps0 = alpha/h ∫(T-Tref)dy`、`kappa = alpha·12/h³ ∫(T-Tref)(y-h/2)dy`
  （逐单元 Simpson，剖面向壁面线性外推），并给出条带自由挠度
  `delta = kappa L²/2` 与全约束残余应力 `sigma = E/(1-nu)·alpha·(Tref-T)`；
- model tests（解析对拍）：
  - 线性剖面 → `kappa = alpha·dT/h` 精确（0.7 1/m）、膜应变为 0；
  - 均匀剖面 → 曲率为 0、膜应变 `alpha·dT` 精确；
  - 对称抛物线 → 曲率为 0（对称性）、膜应变 `alpha·c·h²/12`
    （1024 采样，rtol 1e-4）；
  - 挠度与残余应力手算点精确；
- 翘曲形状（第二阶段）：`moldingWarpage::deflectionProfile(kappa, L, w)`
  由曲率分布求简支条带的 1D 板方程 `w''=-kappa`、`w(0)=w(L)=0` 解；
  model test：均匀曲率下剖面 `w(x)=kappa·x(L-x)/2`（中点 `kappa L²/8`
  精确，最大误差 4e-19 m）；
- 双金属基准（第三阶段）：`moldingWarpage::bimetalCurvature` 实现
  Timoshenko 双层粘结曲率公式，等厚等模量极限退化为
  `3·Δα·ΔT/(2h)`（手算点 0.3 1/m 精确 rtol 1e-12）；
- 待做：三维结构求解（线弹性/`solidDisplacement` 顺序耦合）、脱模
  约束释放、平板/哑铃与文献 ±10% 对比。

## 1. 背景与现状

013a 已提供 PVT 一致的体积收缩与残余热应力**指标**，但不预测翘曲
位移。结构翘曲需要线弹性/粘弹性结构求解与脱模约束释放；上游
`solidDisplacement` 可作为结构求解器基础。

## 2. 目标与非目标

### 目标

1. 从温度/压力历史计算自由应变（PVT 一致），顺序耦合到结构求解；
2. 线弹性翘曲 MVP（平板/哑铃基准）；
3. 脱模约束释放后的自平衡；
4. 与文献/商用结果偏差在可接受范围（±10%）。

### 非目标

- 非线性大变形、接触、疲劳；
- 在线闭环优化。

## 3. 技术方案

- 顺序耦合：流动/传热（moldingFoam）→ 温度/压力场 → 结构求解
  （可复用上游 `solidDisplacement` 或模块内热弹性）；
- 自由应变 `ε_free(T,p)` 由 Tait PVT 给出（013a 的指标升级为应变）；
- 先线弹性、后粘弹性（027）。

## 4. 工作拆解

1. 自由应变与热弹性本构；
2. 结构求解集成（多区域/顺序）；
3. 平板/哑铃基准对比；
4. CI（夜间）与文档。

## 5. 验收标准（DoD）

- 基准件翘曲与文献/软件偏差 ≤ ±10%；
- 残余应力定性分布正确；
- 不影响现有流动求解；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 粘弹性参数缺乏 | 先热弹性 + 自由应变 |
| 耦合复杂度 | 先单向顺序耦合 |
