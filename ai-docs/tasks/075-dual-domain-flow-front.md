# 075：独立降维求解器、面内流动与填充前沿

- 状态：planned
- 优先级：P1
- 依赖：073、074
- 来源：2026-09-15 用户 Dual Domain / Kairos 扩展需求

## 目标与文件规划

新增 `src/dualDomainFoam/` 求解入口、面内压力/速度及前沿模块；
接入 `src/Make/` 或独立 wmake target、`xmake.lua` 和发布打包。
必须能用明确的 dualDomainFoam 命令启动，不借用普通 moldingFoam 静默选路。

## 数值设计流程

1. 写清薄壁低惯性模型的适用域和曲面切平面离散，单元体积 V=A*h。
   控制量 m=alpha*A*积分(rho dz)，守恒方程 dm/dt+边质量通量和=源项。
2. 厚度方向解 d/dz(eta du/dz)=面内 grad(p)，两面无滑移；
   eta 来自共享 Cross-WLF，积分得到面内流量和平均速度。
   非对称温度下不得假设零剪切面恒在中面。牛顿极限恢复
   q=-h^3 grad(p)/(12 eta)，q 为单位边长体积通量。
3. 采用中面三角形守恒离散，明确非正交修正、曲面切向变换、
   厚度突变两侧传导率/通量一致性；共享边只产生一份守恒通量。
4. 解压力与有界 alpha/front，区分未填充区域、排气压力和封闭压力零空间；
   明确干湿前沿通量、浇口注入量、CFL 与非线性迭代控制。
   不能用裁剪 alpha 掩盖质量流失；修正量进入质量预算。
5. 流量/压力浇口、排气、壁面及 VP 事件接口支持 076；
   最大迭代数/步数/非有限数失败显式返回非零，日志保留最后预算。

## 验收标准

- 无 polyMesh 的等温平面薄板真正求解，压力、平均速度、
  剪切速率/应力及前沿位置对照解析解；三网格/三时间步分别变化，
  先冻结误差阈值再运行，不能混淆空间与时间误差。
- 基础质量残差定义为 |m-m0-累计净流入|/max(m0,累计流入,mFloor)，
  mFloor 的量纲/值入字典；小基准阈值不高于 1e-3，
  同时报告绝对 kg 残差和每步残差。
- alpha 有界、闭边零通量、厚度跳变共享边通量相消；降低步长时精度趋势合理。
- 显式 solver 名称/version/schema、网格与材料摘要写入原始日志；
  三维 case 原行为回归通过，无转换体网格或隐式 fallback。
