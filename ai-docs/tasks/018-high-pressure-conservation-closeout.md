- 状态：in-progress（2026-09-10：浇口通量一致性修正 + 平滑封冻已落地；40 MPa hold 守恒仍为 4.5e-2，主因定位为高压压力-密度耦合振荡，修正待做）
- 优先级：P0
- 依赖：009
- 预估规模：3–5 天

### 进展与诊断（2026-09-10）

- **平滑闸口封冻已实现**：`moldingStage::gateSealFactor(t)` + 可选
  `packing.gateSealRamp`（缺省 0，行为不变）；`moldingInletVelocity`
  与 `moldingPrghPressure` 在斜坡内混合到零通量。40 MPa 标定
  （`gateSealRamp 0.05`）守恒 4.49e-2 vs 瞬时封冻 4.57e-2——**封冻
  瞬态不是主因**；
- **主因定位**：高压斜坡/封冻期闸口 `alphaRhoPhi.melt` 出现巨大
  **虚假出流尖峰**（峰值 0.66 kg/s，而正常注入约 7.5e-5 kg/s；2278 个
  正样本），污染通量积分并对应真实的 α 质量通量不一致；叠加封冻后
  冷却收缩时压力未按 pvT 回落（储存质量 0.4 s 内虚假增长 ~2%）；
- **通量一致性修正已实现**（覆写 `prePredictor`）：浇口处强制
  `alphaPhi1 = alpha1*phi`、`alphaRhoPhi1 = rho1*alpha1*phi`，消除
  α 输运在快速压力瞬态下与总通量的不一致；16 个小用例回归全绿；
  小型 40 MPa 密封腔实验（全熔体）显示剩余尖峰源在 `phi` 本身
  （压力-速度耦合的瞬态），量级为物理压缩注入（~4e-3 kg/s）的数倍，
  需与封闭腔压力-密度耦合一并解决；
- 因此收口需要：(a) 闸口 α 质量通量一致性修正（用质量通量校正 α
  通量/抑制边界尖峰，保持 MULES 有界性）；(b) 封闭腔压力-密度-温度
  耦合的稳定离散。两项均在模块内覆写实现。

## 1. 背景与现状

009 已完成机理研究与界面 Pareto 扫描：现状 1.3 MPa 契约 case 质量
守恒 9.38e-04；40 MPa 标定（`validation/highPressure`）显示两条路径——
含气约 5% 时稳定但误差 3.3e-3，全熔体（残余气 0.25%）时封冻/减压段
数值失稳（NaN）。瓶颈是**封冻后近不可压缩熔体的压力-密度-温度耦合**
与界面压缩通量的一致性。

## 2. 目标与非目标

### 目标

1. 40 MPa（可扩展至 100 MPa）保压 case 质量守恒 < 1e-3；
2. 全周期稳定（含封冻、减压、冷却）；
3. 给出误差随保压压力单调可解释的标定曲线；
4. 现有 1.3 MPa 契约 case 误差不劣化，纳入 CI 夜间回归。

### 非目标

- 界面锐化算法重写；
- 相变/多组分输运。

## 3. 技术方案

1. **平滑闸口封冻**：`moldingStage` 暴露封冻斜坡系数，`moldingInletVelocity`
   与 `moldingPrghPressure` 在斜坡内混合到零通量，消除瞬时封冻的压力波；
2. **封冻腔压力-密度耦合**：为封闭域引入参考压力/`pcorr` 式处理或
   ψ 的隐式线性化，稳定近不可压缩熔体的冷却收缩；
3. **α 质量通量一致性修正**（若 1/2 不足）：在模块内覆写修正项，
   保持 MULES 有界性；
4. 用 `validation/highPressure` 标定 10/20/40/80 MPa 误差曲线。

### 诊断修正（2026-09-10，重要）

hp40f 的逐时守恒（窗口从充填到 t）：

| t [s] | 压力阶段 | 守恒误差 |
|-------|----------|----------|
| 1.20–1.30 | 斜坡 30→38 MPa | 6e-4 … **5.02e-4** |
| 1.32 | 斜坡 39 MPa | **3.24e-2** |
| 1.35–1.55 | 40 MPa 平台/hold | **4.2–4.8e-2** |

- 因此 **<1e-3 的窗口只到约 38 MPa（t≈1.30 s）**；升到 40 MPa 平台后
  储存质量（∫αρ dV）出现 **±1% 振荡**（压力-密度耦合在近不可压
  熔体高压端的数值不稳定），守恒跳到 3e-2 并在 hold 期维持 4.5e-2；
- 这意味着 **40 MPa hold 的 DoD 尚未满足**，本任务保持 in-progress。
  浇口通量一致性修正与平滑封冻**单独不足以**解决该高压端的振荡；
- 封冻后冷却收缩（Tait 负压/空洞）是另一个独立问题（018a）；
- **隔离实验（小型密封腔，0.02 s 升到 40 MPa）**：
  - 绝热壁下振荡依旧（入口通量峰值 2.2e-2 kg/s vs 物理压缩注入
    ~1e-4 kg/s 量级），确认振荡源是**压力-速度耦合**而非壁面冷却；
  - `PIMPLE { transonic yes; }` 初试因缺少对应 fvSchemes 条目退出，
    需配套 `div(phid,p)` 等方案后再评估——列为下一步候选；
- **已验证无效的候选**（小型密封腔，绝热壁，0.02 s 升至 40 MPa）：
  - `PIMPLE { transonic yes; }` + `div(phid1/2,p_rgh)` 方案 +
    PBiCGStab/DILU：可运行但入口通量峰值仍 2.1e-2 kg/s（物理量级
    ~1e-4）；
  - `p_rgh` 收紧到 `relTol 0 / tol 1e-9`（PCG）：峰值 2.15e-2；
  - `nOuterCorrectors 5`：峰值 2.5e-2；
  结论：振荡不来自线性容差/外迭代/transonic，而是**浇口定压 BC 与
  密封近不可压熔体在高压端的声学刚性耦合**；
- **补充对照实验**（同小型密封腔）：
  - 上游标准组合（`uniformFixedValue` 定压 + `pressureInletOutletVelocity`）
    替换自定义浇口 BC：振荡仍 1.46e-2（略降）；
  - 斜坡 0.02 s → 0.2 s：振荡不变（1.46e-2，52 个正样本）；
  - 通量时间序列为正（出流）并从斜坡起始单调衰减——是浇口压力
    斜坡起始的**大出流瞬态**（密闭腔声学响应），不是逐步奇偶失稳；
- `nCorrectors 10`：振荡不变（1.50e-2，48 个正样本）；
- **误差窗口分解（hp40g 既有数据后处理）**：

  | 窗口 | Δm (kg) | 积分解通量 (kg) | 残差 (kg) | 相对误差 |
  |------|---------|-----------------|-----------|----------|
  | 充填（0→V/P 切换，t=1.044 s） | +2.2806e-3 | −2.2813e-3 | −7.4e-7 | **3.2e-4** ✓ |
  | 保压（切换→封冻，t=1.555 s） | +2.2496e-4 | −1.1012e-4 | **+1.148e-4** | **51%** ✗ |
  | 到封冻总窗口 | +2.5055e-3 | −2.3914e-3 | +1.141e-4 | 4.55e-2 |
  | 封冻后（→1.694 s） | −6.2e-5 | +5.760e-5 | −4.6e-6 | （Δm 小） |

  结论：**充填期守恒达标；全部超差集中在保压期**——域内质量增长
  （2.25e-4 kg）远超边界入流积分（1.10e-4 kg），即保压斜坡的
  压力-密度-通量不一致（浇口通量尖峰不足以解释，且封冻后绝对泄漏
  仅 4.6e-6 kg）。收口方向明确：保压期的质量通量一致压力耦合，
  而非浇口速度边界（零梯度 U 实验已证伪）。
- `momentumPredictor yes`：出现灾难性负尖峰（min −1.45e3 kg/s，
  max 1.49e-2）——动量预测器与定压入口的声学刚性耦合被放大；
- 入口通量时间序列呈**奇偶交替衰减**（相邻步成对起伏，如
  0.0029/0.0042、0.0025/0.0036、0.0021/0.0027…），提示压力-速度
  耦合在浇口边界存在局部 odd-even 模式；
- **保压期浇口速度边界实验**：`moldingInletVelocity` 保压分支由
  `U = nf·phi/|Sf|·sealFactor`（跟随压力解通量）改为零梯度
  （`patchInternalField()`，去除 U-通量反馈）：入口通量尖峰
  **完全相同**（max 9.6467e-3、min −6.4097e-4、>1e-3 样本 5 个），
  说明尖峰不在速度边界，而在压力/alpha 耦合层；
- **压力目标松弛实验**：为 `moldingPrghPressure` 增加可选 `relaxation`
  （默认 1 不变；`refValue = (1−r)·当前值 + r·目标`）；r=0.2 时入口
  通量峰值基本不变（2.51e-2）——说明尖峰不由 Dirichlet 目标驱动，
  松弛无法收口；该选项作为可选数值阻尼保留（默认行为不变）；
- **关键观察**：`p_rgh` 线性求解残差已收敛到 ~1e-10（无 pcorr 步），
  但浇口边界通量仍为 1.5e-2 kg/s 尖峰——说明是**定压边界上的局部
  通量误差**（近不可压 ψ 极小 → rAUf 大，边界压力误差经
  `valueInternalCoeffs` 放大为通量），全局残差无法约束；
- 结论：该瞬态与 BC 形式、斜坡率、线性容差、外迭代/校正次数、
  transonic 均无关，属**可压缩 VoF 在密闭近不可压腔 + 定压入口组合
  下的格式刚性**；收口需要压力耦合层面的重构（候选：质量通量一致的
  压力入口、ψ 隐式/参考压力正则化、或声学松弛），建议独立会话攻坚。

### 收口结论（原记录，需按上表修正）

- 守恒窗口到约 38 MPa（t≈1.30 s）为止误差 <1e-3（最小 5.02e-4）；
  40 MPa hold 期误差 4.5e-2，未达标；
- **封冻后冷却**：Tait 双域在定质量定容下冷却时要求负压（张力）才能
  保持密度，物理上对应**收缩空洞**；当前可压缩 VoF 无空洞/空化模型，
  密度被高估、表观质量增长（hp40 实测 +2%/0.4 s → 全周期 4.5e-2）。
  该工况移交新任务 **018a**（收缩空洞/负压建模），不计入本任务 DoD；
- 浇口通量一致性修正（prePredictor 覆写）已落地，16 个小用例回归全绿；
  大 case（`validation/highPressure`，endTime 1.35 s）与误差-压力曲线、
  CI 集成留待全部任务完成后统一回归。

- 40 MPa case 质量守恒 < 1e-3（阈值不放松）；
- 1.3 MPa 契约 case 不劣化；
- 误差-压力曲线单调可解释；
- `xmake run test` / `test-solver` / `case-contract` / 新高压 case 全绿；
- CI 双架构绿。
