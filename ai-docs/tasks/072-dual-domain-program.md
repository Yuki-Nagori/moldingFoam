## 背景与边界

Kairos 已有 DualDomainMesh 前处理；当前 moldingFoam 读取三维 polyMesh。
本专项新增显式 `dualDomainFoam`，直接消费中面三角形与厚度数据，
不经体网格近似转换，不改变现有三维求解路径。遵守 GPL-3.0 项目许可，
不引入 Moldflow 专有代码、专有格式实现或未授权材料数据。

当前仅为规划，独立 solver、输入 schema 和下述测试均尚未交付。
仓库已有 `report/mug-moldflow/mug.stl` 与文本报告，但本次未找到参考
Dual Domain 节点/拓扑/厚度/匹配输入；STL 不能唯一恢复这些信息。
`xmake.lua` 的源码默认版本字段为 v0.2.3；CD 在打包前用输入 tag 重写该字段，
不回写源码提交，本地已有 v1.1.0 tag。默认字段不是发布版落后的证据。
材料基线以 v1.1.0 对应提交和实际公式为准，另核对 Kairos 参数语义。

## 统一设计约束

- 降维假设先记录：薄壁、厚度方向无滑移、面内低惯性等适用范围；
  曲率、厚度跳跃、浇口附近三维效应必须明确局限，不能承诺参考软件逐点等价。
- 固定面/边全局 ID、厚度积分顺序、法向方向、单位、压力基准与时间原点；
  所有异常以明确 FOAM IO 错误或数值失败状态结束，无隐式 fallback。
- 数值路线：中面守恒离散 + 广义牛顿厚度流动积分 + 厚度热方程；
  先写离散方程及质量/能量预算，再编码；不能仅输出指标冒充求解。
- 物理未支持清单随版本维护：黏弹性、纤维取向、结晶潜热、残余应力/翘曲、
  喷射/喷泉流、显式空气压缩、完整三维模具 CHT 等须逐项写支持或未实现。
  未实现项不得用既有三维能力自动背书。
