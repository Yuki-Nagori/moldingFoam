# 017 — 基准验证（实验/商用软件对拍）

- 状态：in-progress（2026-09-10：解析基准已入库——Couette 生热、
  Navier 滑移、一维 Stefan 凝固；实验/商用软件对拍待做）
- 优先级：P1
- 依赖：001/002/006（当前周期已自洽）
- 预估规模：1–2 周（按基准数量）

## 1. 背景与现状

当前验证只有函数级 modelTests 与自洽的契约 case，**没有与实验或商用
软件（Moldflow/Moldex3D）的对比**，因此工程精度未标定：

- 充填时间/短射位置；
- 压力曲线（浇口/末端）；
- 温度场与冻结层厚度；
- 顶出时间/制品重量。

## 2. 目标与非目标

### 目标
1. 选取公开标准基准：如
   - 矩形板/哑铃（openInjMoldSim 等开源数据）；
   - 文献中的 1D 充填/冷却解析解；
   - 有条件时与 Moldflow 同一材料/工艺对拍；
2. 建立可重复的对比脚本与容差指标；
3. 输出精度报告（误差条）。

### 非目标
- 全材料库标定；
- 与所有商用软件全工况一致。

## 3. 技术方案

- 基准 case 目录（不进契约 case，单独 `validation/`）；
- 对比指标：
  - 充填时间 rtol；
  - 压力曲线 L2/峰值误差；
  - 温度测点误差；
  - 质量守恒与能量守恒；
- CI：轻量解析基准进 `xmake run test` 或夜间；完整基准夜间跑。

## 4. 工作拆解

1. 基准清单与数据来源评审；
2. `validation/` case 与自动对比脚本；
3. 误差报告模板；
4. 根据结果回溯模型/材料参数；
5. README 第 12 节"验证与精度"。

## 5. 验收标准（DoD）

- 至少 2 个基准（1 解析 + 1 文献/软件）入库并自动对比；
- 给出误差指标与容差；
- 结果随 README/CI 可见；
- CI 双架构绿（轻量项）。

验收记录（解析基准，已入库）：

| 基准 | 目标 | 实测 | 阈值 |
|------|------|------|------|
| `xmake run couette` | 黏性生热（线性 Couette 绝热） | 4.1e-4 | 2e-3 |
| `xmake run couetteSlip` | Navier 滑移剖面 | 3.3e-9 | 1e-4 |
| `xmake run stefan` | 一维 Stefan 凝固前沿（t≥60 s） | 1.55%（t=100 s 0.19%） | 5% |

以上均带独立 Python 验证脚本（CrossWlf/Tait/Neumann 实现独立于求解
器代码）。文献/商用软件（或实验）对拍仍待补充。
