# 028 — 压力依赖粘度模型

- 状态：planned
- 优先级：P2
- 依赖：001
- 预估规模：3–5 天

## 1. 背景与现状

CrossWlf 系数已含压力项 `D3`（当前为 0）。高压注塑（40–100 MPa）下
压力对粘度的影响不可忽略，需启用并验证压力依赖。

## 2. 目标与非目标

### 目标

1. 启用 `D3` 压力依赖（`η0` 随压力指数变化）；
2. 高压基准（与 018 联合）验证粘度/压力分布；
3. 缺省 `D3=0` 行为不变。

### 非目标

- 新的粘度模型形式。

## 3. 技术方案

- `CrossWlf::eta` 已支持 D3；确认并补充文档/用例；
- 与 018 的高压 case 联合标定。

## 4. 工作拆解

1. 启用/校验 D3；
2. 高压基准；
3. 文档与契约。

## 5. 验收标准（DoD）

- D3>0 时粘度随压力单调；
- D3=0 行为不变；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 与 018 的高压数值稳定性耦合 | 联合回归 |
