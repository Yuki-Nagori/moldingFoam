# 021 — 熔接痕与气穴预测

- 状态：done（2026-09-10：fillTime/airTrap 场 + 熔接痕截面峰值判据 + 双浇口基准；前沿相遇的界面级检测为后续扩展）
- 优先级：P1
- 依赖：006/003
- 预估规模：1–2 周

验收记录：

- `constant/moldingDict` 可选 `writeFillTime`（bool，缺省 false）：求解器
  记录每个单元填充（α≥0.5）时刻并写出 `fillTime` 场；`trapAirInterval`
  启用时写出困气单元场 `airTrap`（1 = 困气），复用 003 的连通域诊断；
- 熔接痕判据：壁面单元在每个流向截面最后填充，故取**截面最大填充时间**
  再沿流向找峰值，峰值截面即熔接痕；
- 集成用例 `tests/cases/weldLine`：40×4 mm 通道双端等流量充填、**全顶面
  排气**；熔接痕位于中心面 ±4 cell（实测 2.5 cell，偏移 3.1% 长度），
  截面最大填充时间对称误差 2.5%，困气 12/640 cell；`xmake run
  test-solver` 10 用例全绿；
- 关键发现：小排气口（顶面中心 2 mm）会因困气压缩使双前沿对称性自发
  破缺（α 镜像差 0.27、熔接痕偏移 28.75%），全顶面排气恢复对称；
- 缺省不写 `writeFillTime` 时行为不变；前沿相遇的界面级检测（法向相对
  判据）与三维基准为后续扩展。

## 1. 背景与现状

006 已有排气封堵与 V/P 切换，003 已有困气诊断（连通域洪水填充）。
缺口是**熔接痕位置预测**（多股前沿相遇/汇流）与**气穴分布输出**，
这是注塑件外观与强度评估的核心指标。

## 2. 目标与非目标

### 目标

1. 熔接痕位置预测（前沿相遇检测与标记）；
2. 气穴分布输出（基于困气诊断的压力极小/封闭域）；
3. 基准件（多浇口/带芯）验证；
4. 输出场可供后处理。

### 非目标

- 熔接痕强度/力学性能定量；
- 表面形貌。

## 3. 技术方案

- 前沿到达时间场或 α 前沿相遇检测（相遇面即熔接痕）；
- 气穴：003 的困气连通域 + 局部压力极小，写成标记场；
- 输出 `weldLine`/`airTrap` 场（AUTO_WRITE）或 function object。

## 4. 工作拆解

1. 熔接痕检测算法与场输出；
2. 气穴标记与基准验证；
3. 多浇口/带芯基准 case；
4. CI 与文档。

## 5. 验收标准（DoD）

- 基准件熔接痕位置与解析/文献一致；
- 气穴与困气诊断一致；
- 不影响流动求解；CI 双架构绿。
