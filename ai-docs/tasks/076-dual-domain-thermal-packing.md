# 076：厚度温度、保压冷却与质量能量闭合

- 状态：planned
- 优先级：P1
- 依赖：074、075
- 来源：2026-09-15 用户 Dual Domain / Kairos 扩展需求

## 目标与文件规划

在 `src/dualDomainFoam/` 新增 thicknessEnergy、cycleControl 与 budgets，
使用 074 积分契约与共享 Tait，实现非等温填充、保压、冷却与顶出判据。
补充 `docs/dual-domain-physics.md` 的方程、边界、量纲和适用限制。

## 实施流程

1. 推导厚度温度积分/离散的热方程：面内焓输运、厚度导热、黏性耗散；
   压力功按所选热力学变量与 Tait 一致推导，避免重复计入压缩功。
   给出守恒权重、边界热流和时间推进稳定条件。
2. 两侧独立 Dirichlet 温度或显式换热边界；记录 cavity/core 与法向端点映射。
   无滑移及不对称热边界下更新厚度黏度/流量；积分冻结层或等效停流
   的定义可审查，不将 etaMax 自动等同于有物理依据的冻结。
3. Tait 密度同时进入压力耦合、质量预算与保压补缩，不能只用于最终质量换算。
   相变/潜热若未实现须明确记录，拒绝宣称完整结晶物理。
4. packingCurve 使用相对 VP 时间，时刻严格递增且有限；
   插值、起终点外行为、浇口封冻、反流策略与阶段结束写入 schema。
   injectionTime 是工艺控制参数，实际填满事件另算，不能强制伪造填充结束。
5. 冻结 VP 判据（填充率/时间/压力及优先级）、未填满超时状态；
   明确冷却从何时开始及与保压串行/重叠规则。
   ejectionCriterion 配温度统计口径/阈值、最短冷却时间和最大时限，
   无法达到顶出条件返回未完成，不强行成功。
6. 每步记录入口/出口质量、储存变化、边界热量、焓流、耗散、
   压力功及数值限幅账目，输出累计与归一化残差。

## 验收标准

- 双面等温与不等温一维导热解析测试、绝热守恒测试、黏性耗散与压力功
  单独激活测试；量纲/正负号/法向反转敏感性检查。
- 保压曲线 knot 与中间插值 golden；重复、倒序、NaN 时刻非零失败；
  VP 事件插值、冷却计时与未顶出失败路径可复现。
- 封闭可压缩容腔与注入保压补缩测试，质量残差 <=1e-3，
  能量阈值在独立解析验证计划中先冻结；报告迭代误差和离散误差。
- 076 不以 Mug smoke 代替完整物理测试；输出未实现项与有效假设。
