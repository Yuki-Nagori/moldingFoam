# 030 — 多级注射/保压工艺曲线与过程控制（补充）

- 状态：planned
- 优先级：P1
- 依赖：006/016
- 预估规模：1–2 周

## 1. 背景与现状

当前注射速度为固定 `volumetricFlowRate`，保压为 table 曲线；真实
工艺使用多级速度/位置切换、V/P 切换策略与阀浇口时序。缺口是**工艺
曲线与过程控制**的可配置化（评估新增）。

## 2. 目标与非目标

### 目标

1. 多级注射速度（table/时间或位置分段）；
2. V/P 切换准则配置（时间/位置/压力/填充分数）；
3. 阀浇口时序（与 016 衔接）；
4. 工艺曲线 case 验证。

### 非目标

- 机器闭环控制/硬件接口。

## 3. 技术方案

- `moldingInletVelocity` 支持 `Function1` 流量曲线；
- `moldingStage` 扩展切换准则；
- 与流道网络/阀浇口协同。

## 4. 工作拆解

1. 速度曲线 BC；
2. 切换准则配置；
3. 工艺 case 与验证；
4. 文档与契约。

## 5. 验收标准（DoD）

- 多级速度 case 流量/压力历史与设定一致；
- 缺省（常数流量）行为不变；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 曲线不连续导致数值冲击 | 曲线平滑 + 限幅 |
