# 022 — 翘曲/收缩 MVP（013 分阶段落地）

- 状态：planned
- 优先级：P1
- 依赖：001–012
- 预估规模：2–4 周

## 1. 背景与现状

013a 已提供 PVT 一致的体积收缩与残余热应力**指标**，但不预测翘曲
位移。结构翘曲需要线弹性/粘弹性结构求解与脱模约束释放；上游
`solidDisplacement` 可作为结构求解器基础。

## 2. 目标与非目标

### 目标

1. 从温度/压力历史计算自由应变（PVT 一致），顺序耦合到结构求解；
2. 线弹性翘曲 MVP（平板/哑铃基准）；
3. 脱模约束释放后的自平衡；
4. 与文献/商用结果偏差在可接受范围（±10%）。

### 非目标

- 非线性大变形、接触、疲劳；
- 在线闭环优化。

## 3. 技术方案

- 顺序耦合：流动/传热（moldingFoam）→ 温度/压力场 → 结构求解
  （可复用上游 `solidDisplacement` 或模块内热弹性）；
- 自由应变 `ε_free(T,p)` 由 Tait PVT 给出（013a 的指标升级为应变）；
- 先线弹性、后粘弹性（027）。

## 4. 工作拆解

1. 自由应变与热弹性本构；
2. 结构求解集成（多区域/顺序）；
3. 平板/哑铃基准对比；
4. CI（夜间）与文档。

## 5. 验收标准（DoD）

- 基准件翘曲与文献/软件偏差 ≤ ±10%；
- 残余应力定性分布正确；
- 不影响现有流动求解；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 粘弹性参数缺乏 | 先热弹性 + 自由应变 |
| 耦合复杂度 | 先单向顺序耦合 |
