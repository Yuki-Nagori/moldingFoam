## 1. 背景与现状

充填前沿的喷泉流（fountain flow）决定表皮取向、熔接痕与表面质量，
是注塑充填的经典验证对象。当前 017 只覆盖 Couette/滑移/Stefan，缺少
前沿形状与前沿附近速度/温度场的定量验证。

## 2. 目标与非目标

### 目标

1. 建立 2D 矩形腔喷泉流基准（前沿位置、速度场、温度场）；
2. 与解析/文献结果对拍，定义 L2 范数误差指标；
3. 网格/时间收敛；
4. 纳入 CI 夜间回归。

### 非目标

- 三维前沿破碎/喷射；
- 表面张力主导的流动。

## 3. 技术方案

- 2D 矩形腔、恒定流量充填，前沿由 VoF 追踪；
- 与文献喷泉流速度/温度剖面（如 Mavridis 等的解）数字化对拍；
- 前沿位置随时间与解析充填时间对拍；
- 网格加密与时间步收敛。

## 4. 工作拆解

1. 文献/基准选择与数据整理；
2. `validation/fountainFlow` case + 验证脚本；
3. 收敛性研究；
4. CI 集成与文档。

## 5. 验收标准（DoD）

- 前沿位置相对误差 < 5%；
- 前沿附近速度剖面与文献偏差 < 10%（L2）；
- 网格/时间加密误差下降；
- 现有 case 不劣化；CI 双架构绿。

## 6. 风险与缓解
