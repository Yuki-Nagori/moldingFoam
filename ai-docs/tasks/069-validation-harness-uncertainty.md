- 状态：in-progress
- 优先级：P2
- 依赖：063 / 035 / 045 / 047 / 049

## 背景与现状

063 为新增回归补了有界执行和失败日志上传；通用 run-solver-tests 仍存在
预期失败分支临时目录未清理、串行无 timeout、串行失败后并行前删除证据的
问题。现有精度证据仍偏解析小基准；不能将两点阶估计或质量预算当成整件误差。

## 目标与非目标

先保证测试失败可被发现并保留证据，再建立目标量的空间/时间/参数不确定度
矩阵和外部定标任务入口。完整矩阵由 nightly 执行。

## 工作拆解与涉及文件

1. `scripts/run-solver-tests.sh`：串行与网格步骤有界；保留独立串/并行失败
   日志；清理成功临时目录；预期失败需要特定报错且不得被其他崩溃误满足。
2. Python 验证器核对 uniform/nonuniform、声明长度、所有分量有限性及
   同一物理时刻；用干净/故障合成数据自证，拒绝空样本与 NaN 漏检。
3. `.github/workflows/nightly.yml`：失败日志与关键输入 artifact 可追溯；
   063 的双架构/契约结果补入其验收记录，不另起重复完成任务。
4. `ai-docs/uncertainty.md`：针对压力、热通量、取向、翘曲分别制定三网格/
   三时间步研究；区分离散误差、材料定标误差与实验误差。

## 验收标准

模拟超时、网格失败、串行失败而并行成功均使 harness 正确失败并保留原始
证据；成功临时目录被清理。验证器对坏数据拒绝、对干净数据通过。
收敛矩阵脚本有资源预算与原始数值出处，不在本地跑全量；无外部数据时明确
记为未定标，不用自洽模拟结果替代实验。

共享 DoD 仍适用：构建无新增告警、相应最小测试及完整 CI/契约验收，记录
提交哈希与取证口径后再标 done。遵循 `../diagnostics.md`。

## 风险与缓解

判据强化可能暴露旧测试的假绿，必须先定位原因而非批量放宽门槛。
统计用例数不等于覆盖率；模型启用、结果响应、精度与失效灵敏度分开记录。

### 补记 2026-09-15：矩阵误判修复与验收口径更正

此前“矩阵模式仍要求有限值并记录误差”的描述早于实际实现；当时只绕过
阈值，且可能同时打印 FAIL/PASS。本次补齐 `validation_metrics` 的严格
ASCII 字段解析、声明长度/分量有限性、明确 hex 块尺寸和最终输出时刻检查。
不再从顶点/分级三元组取尺寸，也不再按字段长度猜网格或将截断的
nonuniform 单行扩展成 uniform。

常规结构验证仍保持 8% 阈值；矩阵只对精度门槛采用 MEASURED 记录，写入
value/reference/relative_error/threshold/within_threshold/time，坏数据、
求解失败和翘曲应力失衡仍返回非零。矩阵缺少指标文件同样失败；逐行独立
保留输入、完整求解输出、JSON 和 TSV，执行完所有行后汇总失败。

修复倍率 1 被误判未修改、翘曲应力硬编码下标、加密后 T/e 初值长度不匹配、
