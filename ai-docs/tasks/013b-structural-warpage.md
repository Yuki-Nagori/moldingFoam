# 013b — 结构翘曲集成（顺序耦合，013/022 的落地）

- 状态：planned
- 优先级：P2
- 依赖：013a（收缩/残余应力指标）、018a（空洞/自由应变）、022（solidDisplacement 基准）、023（残余应力模型）、027（粘弹性）
- 预估规模：2–4 周

## 1. 背景与现状

022 已交付并验收了两块基础：

- 解析/指标层：自由翘曲 κ=αΔT/h、条带挠度、Timoshenko 双金属、
  1D 自平衡残余应力、PVT 收缩 S 与热应力指标（013a/023）；
- 结构求解层：`validation/thermoelastic`（`solidDisplacement`）三维
  悬臂基准，自由端挠度与 κx²/2 误差 5.46%（48×80，网格收敛），
  `xmake run thermoelastic` 与夜间 CI 已接入。

缺口：把注塑求解器的温度/压力/收缩历史**映射**为结构求解的热载荷与
自由应变，得到真实制品的翘曲与残余应力（单模块内的顺序耦合）。

## 2. 目标与非目标

### 目标

1. 顺序耦合：moldingFoam 结果（T、p、ρ、S、voidFraction）→
   `solidDisplacement` 输入（热应变 + 自由应变 + 约束条件）；
2. 平板/哑铃基准的翘曲与残余应力，解析/文献对比 ±10%；
3. 顶出后的约束释放（自平衡）与自由翘曲；
4. 缺省不影响现有流动求解与用例。

### 非目标

- 双向耦合（熔体流动受变形反馈）；
- 接触、大变形、疲劳、在线优化；
- 完整粘弹性历史（先用温度相关热弹性 + 自由应变，027 的
  UCM/Giesekus 本构作为后续升级）。

## 3. 技术方案（待评审）

- **顺序耦合数据流**：在顶出时刻（或指定时刻）导出
  - `T`（熔体温度场）→ `solidDisplacement` 的热载荷；
  - PVT 一致自由应变：`ε_free = 1 − (ρ_ref/ρ)^(1/3)`（等温线膨胀
    等效）或按 013a 的 `S` 折算；
  - 空洞区（`voidFraction`）不承载：以材料退化（E→0 或空单元）表示
    或作为几何空隙处理；
- **映射工具**：新增后处理脚本/函数对象，将源区域（mold 流道/型腔）
  的场插值到结构网格（相同网格可直接复用，`solidDisplacement`
  读取 `T` 边界即可）；
- **基准件**：平板（自由收缩/约束收缩）、哑铃（各向异性收缩），
  与 022 的解析解、Timoshenko 双金属、文献对比；
- **验证顺序**：均匀场 → 线性梯度 → 真实注塑 T 场。

## 4. 工作拆解

1. 映射方案与脚本（时间/场选择、单位/参考态一致性）；
2. 平板自由收缩与约束收缩基准（解析对拍）；
3. 真实 T 场（复用 `validation/moldCHT`/`stefan` 或小型注塑 case）
   的单向耦合与翘曲评估；
4. 约束释放/自平衡（顶出后用例）；
5. 残余应力分布与 023 指标的一致性检查；
6. 文档、CI 接入与回归。

## 5. 验收标准（DoD）

- 平板/哑铃基准翘曲与解析/文献偏差 ≤ ±10%；
- 残余应力分布定性正确（表层压/芯部拉的自平衡剖面）；
- 顺序耦合不改动流动求解结果（现有 case 逐字节或数值一致）；
- `xmake run test`/`test-solver` 与夜间 CI 绿（双架构）。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 源/目标网格与参考态不一致 | 先用同网格单区域（型腔即结构域）做通 |
| 自由应变定义（PVT vs 线膨胀）误差 | 与 013a/018a 的 PVT 指标交叉验证 |
| 空洞/未完全填充区的材料描述 | 先材料退化，后空单元/接触 |
| 映射工具复杂度 | 脚本首版仅支持同网格/等距插值 |
