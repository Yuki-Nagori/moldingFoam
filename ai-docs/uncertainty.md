# 数值不确定性量化（任务 035，阶段 1：弯曲类基准）

日期：2026-09-12。对象：`validation/thermoelastic`（三维热弹性悬臂）与
`validation/warpagePlate`（双层收缩翘曲板）。

## 1. 方法

- **网格细化序列**（≥3 级，h 减半）：记录目标量（自由端中性轴挠度）
  与解析值的相对误差；
- **观测阶** `p = ln(e_coarse/e_fine)/ln(r)`（r=2）；**GCI**（Roache）
  `GCI = 1.25·e_fine/(r^p − 1)`；
- 无法给出单调阶时，报告**有界误差区间**（保守）并据此设阈值。

## 2. thermoelastic（48×80 最优网格，κx²/2 解析）

| 网格 | 误差 |
|------|------|
| 6×10 | 86.5% |
| 24×40 | 14.5% |
| 48×80 | **5.46%** |

- 观测阶（24×40→48×80）：`p ≈ 1.42`；
- GCI（48×80）：`1.25×0.0546/(2^1.42−1) ≈ **4.0%**`；
- 验证器阈值：10% → **8%**（实测 5.46%，余量 1.47×）。

## 3. warpagePlate（Timoshenko 双层弯曲解析）

| 网格 | 误差 |
|------|------|
| 48×16 | 4.2% |
| 96×32 | 6.1% |
| 192×64 | 4.9% |

- 误差在 **4–6% 区间非单调振荡**（层间本征应变间断处的高斯积分
  相位误差），未见随 h→0 单调减小；报告**有界误差 ≤6.1%**；
- 该非单调性说明不能用 Richardson 外推收紧到 GCI；阈值取
  **8%**（实测上限 6.1%，余量 1.31×），并在验证器中记录该依据。

## 4. 结论与局限

- 两个弯曲基准的 FV 离散误差 ≤6.1%，阈值收紧为 8%（原 10%）；
- 局限：仅两点推算 thermoelastic 的观测阶（GCI 粗糙）；
  warpagePlate 的界面相位误差未做解析归因；
- 后续（035 阶段 2）：`fountainFlow` 时间/网格收敛（020 已覆盖时间
  收敛）与 `moldCHT` 界面量的网格研究，用通量积分量替代单点。
