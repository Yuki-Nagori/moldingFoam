# 064：检查点完整性与多周期时间语义

- 状态：in-progress
- 优先级：P1
- 依赖：063 / 061 / 012 / 030
- 来源：2026-09-15 整体复核；承接 063 以外的明确剩余项

## 背景与现状

063 保存了周期初态、预算和逐出口状态，但 `moldingFoam` 构造函数仍以
`runTime.value() > small` 判断重启：首次从非零 startTime 开始会被当成重启，
要求并不存在的 moldingInitial。现有最小对拍从 0 开始且只有 T/p/alpha，
没有覆盖 tau 初态、完整升压 ramp、空洞发展后的真实参考历史或换分解。
工艺曲线/阀时序仍为绝对时间，不能把周期重置误解为工艺曲线自动重复。

## 目标与非目标

明确区分首次启动与检查点续读；检查点包含版本、周期编号、网格/分解约束
及必需状态。为曲线增加显式时间基准设计，缺省保持绝对时间兼容。
不承诺任意网格之间重映射；先对不支持的恢复方式提供明确拒绝。

## 工作拆解与涉及文件

1. `moldingFoam::moldingFoam()`：替换按时间正负分类，定义首次非零启动；
   检查快照和周期/预算历史是否属于同一运行，缺项不静默重建。
2. `moldingStage` 与入口/压力边界：验证逐出口、pSwitch/tSwitch/rampArmed、
   非常量 Function1 的连续性；明确 legacy 文件哪些状态不能恢复。
3. `scripts/verify-review-regression.py`：加入非零首次启动、非零 tau、
   升压中段续跑；比较完整目标时刻而非只比较文件存在。
4. 设计周期时间基准及兼容规则，实施前同步 README 和契约说明。

## 验收标准

首次 startTime=1 的两周期运行成功；连续/中断恢复的周期编号和关键场一致；
删除一个必需历史文件时明确失败；非平凡 ramp/曲线在同物理时刻一致。
每个本地载体不超过 1000 单元/几十步；重分解与多区域矩阵交 nightly。

共享 DoD 仍适用：构建无新增告警、相应最小测试及完整 CI/契约验收，记录
提交哈希与取证口径后再标 done。遵循 `../diagnostics.md`。

## 风险与缓解

严禁用中途场补造初态；设置默认时间基准会改变已有工艺，必须显式兼容。
预算基准与密度修正后的 EOS 重建需要独立对拍，不能只测零通量导热。

## 实施记录 2026-09-15

首次启动与检查点续读不再由非零时间值推断；仅当周期初态快照存在时才启用
`MUST_READ`。这覆盖了非零 `startTime` 新鲜启动的确定性缺陷。完整历史版本、
时间基准和重分解契约仍待 CI/契约用例验收，任务保持进行中。

载体缺少 OpenFOAM 要求的 `1/` 初态目录，补齐后通过；完整中断恢复和重分解仍待
nightly 契约。
