# 016 — 流道/热流道耦合

- 状态：planned
- 优先级：P3
- 依赖：001/006
- 预估规模：1–2 周

## 1. 背景与现状

当前契约 case 把浇口当作注入口边界（给定流量/压力曲线），没有显式
流道系统。真实热流道/冷流道中：

- 流道内压力损失影响实际浇口压力与充填平衡；
- 热流道温度控制影响熔体入口温度；
- 多浇口分流需要流道网络平衡。

## 2. 目标与非目标

### 目标
1. 一维流道网络模型（压力-流量-温度沿程）与三维型腔耦合；
2. 支持热流道温度控制（等温/加热功率）；
3. 多浇口分流。

### 非目标
- 流道三维网格共轭求解（可与 008 结合）；
- 冷料井/废料处理。

## 3. 技术方案

- 路线 A（推荐起步）：**1D 流道网络**（等效阻力 + 能量方程），作为
  多浇口边界条件的上游，与型腔入口耦合（压力/流量/温度迭代）；
- 路线 B：流道也划入三维网格，与型腔同一 VoF 求解（简单但网格量大）；
- 与 006 的 V/P 切换衔接：流道网络参与保压压力传递。

## 4. 工作拆解

1. 网络拓扑/参数字典（直径、长度、温度）；
2. 1D 求解与三维入口耦合迭代；
3. 多浇口分流平衡验证；
4. 演示 case 与文档。

## 5. 验收标准（DoD）

- 单流道压力损失与解析 Hagen–Poiseuille 对拍；
- 多浇口流量分配与阻力比一致；
- 缺省（无流道）行为不变；
- CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 网络-三维耦合收敛慢 | 松弛迭代 + 初值继承 |
| 材料在流道内的温度演化 | 1D 能量方程与 CrossWlf 一致 |
