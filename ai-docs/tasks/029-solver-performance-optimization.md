## 1. 背景与现状

现有 case 为万级网格、多周期；工业算例达百万级网格。当前性能
瓶颈：界面库朗限制的时间步、压力线性求解、I/O 与内存。029 负责
并行效率、内存占用与大规模算例可用性。

## 2. 目标与非目标

### 目标

1. 百万级网格算例可运行（时间/内存预算内）；
2. 并行效率（4/8/16 进程弱扩展）达标；
3. 内存与 I/O 优化；
4. 建立性能基准与 CI 时间预算。

### 非目标

- GPU 移植（可评估）。

## 3. 技术方案

- profiling（perf/时间分解）定位热点；
- 线性求解器/预条件选择、分解方法、通信优化；
- 字段内存/临时量复用、I/O 格式（binary/压缩）；
- 与 018 的时间步优化协同。

## 4. 工作拆解

1. 性能基准与 profiling；
2. 热点优化（线性求解/通信/内存）；
3. 大规模 case 与弱扩展测试；
4. CI 时间预算与文档。
