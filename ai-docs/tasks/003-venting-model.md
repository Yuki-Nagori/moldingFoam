# 003 — 排气反压/困气模型

- 状态：planned
- 优先级：P3（当前契约 case 无困气；复杂型腔才需要）
- 依赖：无
- 预估规模：3–5 天

## 1. 背景与现状

当前空气相以 `perfectGas` 建模、顶部 `vent` 为开放边界：填充时空气
自由排出，vent 处压力恒为参考压力。真实注塑的两个缺陷模式没有被
覆盖：

1. **排气反压**：排气通道有限，空气被压缩导致腔内背压上升，填充
   后期注射阻力增大；
2. **困气（air traps / dieseling）**：封闭区域（流前沿合拢处）的
   空气无法排出，被压缩到高压高温，造成短射、困气烧痕。

当前模型里 vent 是全开边界，任何与 vent 连通的区域都不会憋压；
完全封闭区域（不连通 vent 的 cell zone）OpenFOAM 会因压力参考点
缺失而病态。

## 2. 目标与非目标

### 目标
1. 支持配置"排气受限"：vent 边界反压随已排出空气量（或空气相占
   体积）升高，可复现背压上升；
2. 支持困气区检测与压力演化（诊断输出：困气区位置、峰值压力、
   最高温度——烧焦风险指标）；
3. 契约字典可选启用（缺省关闭 = 现有开放 vent 行为）。

### 非目标
- 空气-熔体界面处气体溶解/渗透；
- 模具分型面几何级的排气槽建模（由 case 网格决定）。

## 3. 技术方案选项

### 选项 A：反压边界条件（推荐起步）
新边界条件 `ventingPressure`（air 相 p 场 vent patch）：按 vent
patch 排出的空气质量流量积分（`sum(phi_air·rho_air·neg?)`）计算
滞留空气质量 `m_air(t)`，反压取
`p_vent = p0·(m_air0/m_air)^γ`（等熵压缩）并作为 `totalPressure`
类的边界值。需要 air 相质量通量的获取方式（phase flux 已有
`alphaRhoPhi2`）。

### 选项 B：困气区压力修正
检测无出口连通的空气 cell 集合（对 alpha2 < 阈值的连通域做一次
拓扑标注），对该区域施加 `totalPressure`-型压缩关系（体积减小 →
压力/温度上升），仅做诊断输出时不修改求解，只打印报告。

### 选项 C：A + B 组合
先 A 后 B，A 的质量积分是 B 的基础。

## 4. 工作拆解

1. 模型选择评审：确认契约级需求（是否需要反压影响流场，还是仅
   诊断）；
2. （选项 A）新 BC `ventingPressureFvPatchScalarField`：
   - 参照 `moldingPrghPressure` 的类结构（自注册、`write`、拷贝
     构造族）；
   - 状态量（累计排出质量）需要持久化 → regIOobject 或 BC 内
     `autoPtr`+`write`（重启续跑）；
3. （选项 B）困气诊断 function object 或求解器后处理钩子：
   连通域标注（`regionSplit`）+ 体积/压力报告 → `postProcessing/`；
4. 契约字典：`constant/physicalProperties.air` 或 `moldingDict`
   增加可选 `venting` 组（缺省关闭）→ 契约变更日志；
5. 验证 case：构造一个两端进胶、中部困气的演示 case（新目录，
   不进契约），验证困气压力上升与短射；
6. modelTests：等熵压缩关系单测（给定 m(t) 序列验证 p_vent）；
7. 文档：README 第 6 节新增小节 + 变更日志。

## 5. 验收标准（DoD）

- 缺省（不启用 venting）：与当前基线逐位一致（回归）；
- 演示 case 中困气区压力随填充单调上升且报告输出正确；
- modelTests 新增项 PASS；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| air 相质量通量在并行界面上的守恒 | 使用既有 `alphaRhoPhi2`（与能量方程同源），gSum 前先 `fvc::sum` 校验 |
| 反压模型参数（γ、滞留体积）难以标定 | 参数全部字典化；契约缺省关闭 |
| 连通域标注每步开销 | 只在填充阶段每 N 步执行一次 |
