# 033 — 空洞/张力场建模（018a 阶段 4）

- 状态：in-progress（2026-09-12：公式化澄清——限压力 + 空洞变量；实现待做）
- 优先级：P1
- 依赖：018a（后处理指标：voidFraction/精确 Tait/PVT 对拍 1.6e-6）、031
- 预估规模：1–2 周

## 1. 背景

018a 以 PVT 后处理指标实现封冻后空洞（`voidFraction` 场，压力路径与
PVT 一致 1.16%、密封冷却质量预算 4.1e-4），但求解器仍允许熔体压力
降到 −4.2 MPa 的张力；空洞没有显式体积/质量记账。

## 2. 目标

1. **张力限制**：封冻后压力下限 pv（缺省 0/蒸气压），密度限制在
   `rho(pv,T)`；
2. **显式空洞记账**：空洞体积分数与熔体质量分开守恒
   （`m_melt = Σ V(1−void) rho(pv,T)`）；
3. 密封冷却 case：空洞体积与 PVT 一致 <1%、无修正器下熔体质量
   守恒 <1e-3、压力平台在 pv；
4. 缺省不启用时现有 case 逐字节不变。

## 2a. 公式化分析（2026-09-12，实现前澄清）

- 密封冷却 → 等容压力沿 PVT 等容线下降；当 p 需求低于 pv 时出现空洞。
  **空洞态**：熔体占据 `V_m = m/rho(pv,T)`，空洞体积
  `V_v = V − V_m > 0`；**体密度** `rho_bulk = m/V < rho(pv,T)`
  （低于 pv 态密度，不是高于！）；
- 因此“把体密度限幅到 `rho(pv,T)`”是**错误方向**；要限制的是
  **压力**（EOS 反演 p→max(p,pv)），并引入**第二个变量**（空洞体积
  分数）以保持 EOS 一致：`rho_bulk` 与 `void` 两个自由度，质量守恒
  `m = V(1−void)rho(pv,T)` 闭合；
- 候选实现：
  1. **两场表述**：体密度 + `void` 场，p 由 `max(p,pv)` 钉住，空洞
     体积进质量记账（`massBudget` 扩展）；
  2. **空洞相**：复用空气相（p=pv 的等压腔）表示空洞，αvoid 由收缩
     生成——与现有两相 VoF 兼容但改动大；
  3. **折中（先做）**：仅 p 钉住 + 现有 `voidFraction` 指标/记账
     （EOS 一致性放宽，记录误差界），验证稳定性与守恒收益后再升级；
- 现有 `voidFraction` 指标 `1 − rho_bulk/rho(pv,T)` 与上式一致
  （`void = 1 − m/(V rho(pv,T))`）——指标层无需改动，缺的是求解器
  侧的 p 钉住与空洞记账。
- **朴素 p 钉住实验（2026-09-13，阴性）**：在 thermo 更新后把封冻熔体
  单元的 `p_rgh` 钳制到 pv（`fixedFluxPressure` 兼容性处理后）：
  - 运行稳定，但**密度随即跟随 EOS 滑到 `rho(pv,T)`，空洞质量丢失**
    ——域质量 5.9693e-5 → 5.9173e-5 kg（**−0.87% 质量汇**，预算残差
    −5.06e-7），`voidFraction` 归零（体密度=EOS 密度）；
  - 结论：**必须**把空洞体积/质量显式纳入连续方程（两场/空洞相），
    局部钳制不可行——实证支持第 2a 节的分析；代码已回退。
- **fvModel 压力钉实验（2026-09-13，受阻）**：实现并注册了
  `moldingVoidPressurePin`（相对对角罚项：diag←diag(1+pin)、
  source←source+pin·diag·pv；`addSupFields/addsSup(alpha,rho,field)`、
  四个网格钩子），配合求解器 ψ 置零：**框架从未以 `p_rgh` 查询本模型**
  （实测查询名仅为 `U`/`e.melt`/`e.air`/`rho.melt`/`rho.air`，即
  动量/能量/相方程；压力方程的 `sourceProxy(alpha1, rho1, p_rgh)`
  未按预期派发）→ 钉不生效（压力仍 −4.23 MPa，质量同基线）。
  这是一个**框架层集成障碍**：需改用压力方程可派发的机制（如自定义
  求解器覆写 `pressureCorrector` 注入罚项矩阵、或上游 fvModels 的
  压力源约定）；fvModel 与求解器改动已回退（工作区干净、回归全绿）。
- **压缩性置零实验（2026-09-13，阴性）**：在空洞单元把热力学 ψ 置零
  （密度不再随压力变化 → 质量守恒、压力停住）：**压力方程奇异发散
  （27687 NaN）**——密封腔全域零压缩性 + 无压力参考钉使系统存在零空间。
  这是第三次实证：必须在**压力方程层面**引入空洞变量/压力约束
  （两场、空洞相或变分不等式），局部场修改不可行；
- **钳制 + 密度冻结实验（2026-09-13，阴性）**：在首次触发时捕获体密度
  参考并逐步恢复（保证质量不流失）：**求解发散（质量 NaN）**——压力
  方程在钉住单元失去可压缩性来源（一致性断裂），两场/空洞相表述是
  唯一稳健路径（压力方程需含空洞体积的压缩性贡献）。两次局部实验
  均证伪，代码逐字节回退（diff=0）。

## 3. 技术方案

- 在热物性更新后对密封单元施加 p 下限（限幅 p→pv 并同步
  `correctRho`/能量），或引入空洞相 αvoid 的三相表述；
- 质量记账：熔体质量用 (1−void) 加权，进入 `massBudget` 仪表；
- 与 031 的压力一致定式协同（限幅后的压力方程源项一致性）。

## 4. 验收标准（DoD）

- `tests/cases/voidFraction` 扩展（张力限制开关 + 空洞守恒检查）；
- 模型测试（限幅/记账的单元检查）+ 全套回归绿；
- 密封冷却质量守恒 <1e-3（**无** `massFixGlobal`）。
