# 014 — 结晶动力学（半结晶聚合物）

- 状态：planned
- 优先级：P3
- 依赖：001（潜热）
- 预估规模：1–2 周

## 1. 背景与现状

hMelt 用固定带宽的潜热平台等效相变，不区分结晶度演化。半结晶
聚合物（PP/PE/POM 等）的结晶度受冷却速率与压力影响，进而影响：

- 密度/比容（Tait 双域是准静态近似）；
- 黏度（结晶开始后急剧上升）；
- 最终力学性能与收缩。

## 2. 目标与非目标

### 目标
1. 引入相对结晶度 `χ(t,T,p)` 演化方程（如 Nakamura/Avrami 或
   Schneider 模型）；
2. 潜热释放与 `χ` 耦合（替代固定平台）；
3. 结晶度对黏度/密度的修正接口；
4. 与 DSC 等温/非等温数据对拍。

### 非目标
- 晶体形态学/球晶尺寸分布；
- 后结晶/退火（可后续扩展）。

## 3. 技术方案

- `χ` 作为附加标量场，随物质输运 + 源项（成核/生长）；
- 表观热容中的潜热按 `L·dχ/dT` 释放（与 001 的 `latentCp` 接口兼容）；
- 黏度修正 `η(χ)`（如 `η/η0 = (1-χ/χ∞)^-a`）；
- 参数由 DSC 数据标定（字典化）。

## 4. 工作拆解

1. 模型选型与参数标定流程；
2. `χ` 场与能量方程耦合；
3. 黏度/密度修正接口（CrossWlf/Tait 调用点）；
4. 验证：等温/非等温 DSC 曲线对拍；
5. 文档。

## 5. 验收标准（DoD）

- 等温结晶曲线与 DSC 数据 rtol < 5%；
- 非等温冷却结晶度演化定性正确；
- 缺省（不启用）行为与 001 一致；
- CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 参数标定数据不足 | 先用文献 PP/PE 参数，字典可换 |
| 与潜热平台的重复计量 | 启用 χ 时必须关闭固定 latentCp 平台 |
