## 精度和性能实验设计

1. 分别进行三网格（固定足够小 dt）与三时间步（固定网格）研究，
   记录迭代误差、解析误差、趋势与适用时的收敛阶/GCI。
   非单调、未进入渐近区或未收敛不能强算 GCI。粗网格误差可记录，
   但不能因此放宽最终精度标准；门槛在测量前冻结。
2. 同工况 DD/3D 对照使用相同几何来源、授权材料、初始温度、
   浇口与冷却边界、工艺时间、输出物理时刻和误差目标。
   三维网格独立为现有 moldingFoam 建立，明确模型和网格差异；
   不将 DD 转体网格充当 dualDomainFoam。
3. 先做共同适用的薄板解析对照，再做 Mug 对照；记录厚度方向三维网格分辨率、
   两种网格积分体积和差异，材料基准与阶段定义不匹配时标记不可直接比较。
4. 同一 of14 会话、同一硬件/线程/rank 设置、至少三次有效重复，
   原始 CSV/JSON 记录节点、三角形或体单元数、积分点数、步数/迭代数、
   峰值 RSS（MPI 同时报各 rank 与总量）、墙钟及统计分散度。
   生成/分区/求解/I/O 分别计时，注明缓存状态。
5. 精度达标后再评估成本。输出 Q_DD、Q_3D、绝对/相对差、
   双方误差依据和原始日志，三维不是天然真值，不声称逐点等价。
   新路径无历史结果时记“原先不支持”，不虚构修改前后性能。
