验收记录（第一阶段：多浇口分流）：

  500 K、htc 2000）实测入口 499.9712 K vs 解析 499.9713 K

## 1. 背景与现状

016 已落地 1D 流道网络模型（HP 压降、并联分流、温度演化）与入口/
保压边界耦合、单浇口集成用例。缺口：多浇口分流 case、热流道温度
控制、阀浇口时序、网络-三维迭代收敛，以及与 V/P 切换的完整衔接。

## 2. 目标与非目标

### 目标

1. 多浇口分流 case（按阻力比）与验证；
2. 热流道温度控制（段壁温/加热功率）；
3. 阀浇口时序（可选）；
4. 网络-三维耦合收敛与性能。

### 非目标

- 流道三维共轭求解（可与 019 结合）。

## 3. 技术方案

- 网络拓扑字典扩展（分支/节点）与迭代耦合（松弛）；
- 热流道：段能量方程 + 加热功率；
- 阀浇口：时间/信号触发的通断。

## 4. 工作拆解

1. 多浇口 case 与分流验证；
2. 热流道温度控制；
3. 阀浇口时序；
4. CI 与文档。

## 5. 验收标准（DoD）

- 多浇口流量分配与阻力比一致；
- 热流道温度可控且能量守恒；
- 缺省（无流道）行为不变；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 网络-三维耦合收敛慢 | 松弛 + 初值继承 |
