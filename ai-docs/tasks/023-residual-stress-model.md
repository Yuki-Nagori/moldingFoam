# 023 — 残余应力模型

- 状态：planned
- 优先级：P2
- 依赖：022
- 预估规模：1–2 周

## 1. 背景与现状

022 的翘曲 MVP 使用线弹性；真实残余应力来自不均匀冷却、保压压力
历史与层间收缩差，需要粘弹性/热粘弹演化与脱模后自平衡。

## 2. 目标与非目标

### 目标

1. 残余应力演化模型（热粘弹性）；
2. 与翘曲结果一致（应力→变形）；
3. 基准验证与定性分布。

### 非目标

- 疲劳/长期蠕变。

## 3. 技术方案

- 在 022 的结构框架内加入粘弹性本构（与 027 协同）；
- 应力松弛/体积松弛参数字典化。

## 4. 工作拆解

1. 本构选型与参数标定；
2. 实现与基准；
3. 与 022 翘曲一致；
4. 文档。

## 5. 验收标准（DoD）

- 基准残余应力分布定性正确；
- 与翘曲耦合自洽；
- 不影响流动；CI 双架构绿。

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 参数标定数据不足 | 文献典型值 + 敏感性分析 |

## 7. 涉及文件

| 文件 | 改动 |
|------|------|
| 结构模块 | 粘弹性本构 |
| `validation/` | 基准 |
